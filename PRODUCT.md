# Product

## Register

brand

## Users

Developers and agent builders evaluating Raven as an open-source foundation for
multi-agent collaboration. They encounter the product through the GitHub
repository, README, banner, and installation path before deciding whether to
try it.

## Product Purpose

Raven is the Harness of Harnesses: a continuously evolving system for building,
coordinating, and improving specialized agent harnesses. The public brand
surface should make that architecture legible quickly and give technically
serious readers a reason to explore the repository.

## Brand Personality

Open, mechanical, collaborative. The voice should feel like an engineered
system with room for many agents and contributors, not a single opaque model
product.

## Anti-references

Avoid generic SaaS positioning, diagram-heavy ecosystem maps, decorative node
or orbit geometry, and canned AI marketing language. Avoid implying that a
public positioning phrase is itself a runtime capability when the code does not
support that claim.

## Design Principles

- Make the relationship between Raven, agent harnesses, and the wider ecosystem
  immediately legible.
- Use concise, high-signal language that can survive a README scan and a small
  banner render.
- Preserve Raven's dark, restrained, EverMind Yellow visual identity while
  making the ecosystem feel open and active.
- Keep public claims aligned with what the current repository actually ships.

## Accessibility & Inclusion

Use high-contrast text and preserve readable spacing at README display sizes.
Keep descriptive alt text aligned with the banner's public message. Avoid
relying on color alone to communicate the product concept.
