# 图标与符号领域模式

本文件保存领域路由、语义、光学、标准和消费检查。主流程与 claim ceiling 见 `SKILL.md`；工具选择见 [工具能力档案](tool-profiles.md)。只读取当前任务触发的章节。

## 1. 子型与相邻边界

| 子型 | 核心对象 | 优先证据 | 不属于本领域的部分 |
| --- | --- | --- | --- |
| UI 操作/导航/对象 | 界面中的动作、目的地和对象 | 项目与平台惯例、真实落位、最近邻、方向 | 控件焦点、命中区和业务状态 |
| 公共信息 | 公共场所中的指代与引导 | 当前公共信息标准、受众理解、安装条件 | 完整空间路径、地图与建筑规划 |
| 安全/运营 | 警告、禁止、命令、运行状态 | 风险、注册符号、冗余、目标用户和审批 | 法规解释与安全责任签认 |
| 设备 | 面板、连接、功能与设备状态 | 设备标准、维护人员、材料与观看条件 | 设备逻辑、控制系统与工程认证 |
| 品牌相关 | 已批准身份的微缩版或功能图标家族 | 品牌母版、功能识别、授权与制作 | 身份策略、标志和字标终审 |

地图中的图形可由本领域拥有几何和语义，但空间比例与图例系统由地图领域拥有。图标字体的符号语义归本领域，OpenType、hinting 与字体指标可由字体领域协作。动画是图形状态的表达方式；宿主状态机仍由产品或组件 concern 拥有。

## 2. 语义证据卡

每个新语义或被修改的公共语义先记录：

```text
stable_id 与本地化名称
主型：对象 / 动作 / 状态 / 指代 / 身份微缩
受众、宿主、观看时间、环境和输入方式
真实对象、动作、约定或权威原件
必留特征、可删细节和唯一消歧特征
最近邻、禁读项、危险误读与误读后果
方向、文化、标准、许可和批准边界
文字、声音、触觉、教学或确认等冗余
```

### 形态骨架

- 对象先保稳定母轮廓，再加入一个在最小尺寸仍存在的强消歧特征。
- 动作同时表达对象、方向与结果；箭头不替代对象或结果，相反动作应改变起终点或重心。
- 状态先区分正常、进行、注意、失败、禁止和未知，再区分原因；关键差异不得只靠颜色。
- 若抽象含义无法稳定图像化，保留标签、上下文或教学，不用装饰细节伪装成通用符号。
- 最近邻必须在相同尺寸、背景、时长和标签条件比较，不能靠展示顺序或分类色消歧。

## 3. 风险生成验证计划

不使用固定人数、固定通过率或固定全矩阵。先声明 claim、误读后果、可逆性、受众差异和真实条件，再由匹配 authority 预注册方法、样本、阈值、编码和失败返回。

| Claim | 最小证据方向 | 不能外推为 |
| --- | --- | --- |
| 构造清楚 | 作者或独立设计者的无标签首读、最近邻与真实尺寸检查 | 目标用户理解 |
| 知觉要素可辨 | 目标受众在命名尺寸/环境下识别构成元素 | 正确理解完整含义 |
| 指代关联成立 | 熟悉该 referent 的用户完成匹配或关联任务 | 陌生公众自然理解 |
| 界面功能可识别 | 真实宿主中的查找、选择或操作任务 | 跨平台或脱离上下文理解 |
| 公共信息可理解 | 命名人群、语言和环境中的自由命名与混淆数据 | 其他辖区或安全部署 |
| 安全/运营可行动 | 高风险人群测试、危险误读分析、冗余和责任人签认 | 法规符合或现场有效，除非另有 coverage |
| 现场有效 | 同版资产在命名地点、距离、材料和任务中的证据 | 其他现场或新 build |

理解实验按风险选取自由命名、匹配、指代关联、知觉质量、短时扫视、方向判断或真实任务；记录原始回答、未知、停顿、混淆方向、测试顺序、设备、尺寸、光照、培训背景和限制。标签辅助后的正确不能覆盖无标签危险误读。

## 4. 标准与权威路由

标准名称是查找入口，不是合规声明；使用时核对当前版本、辖区、许可、适用范围和责任人。

- **公共信息：** 优先查 ISO 7001 类注册公共信息符号及本地规定；其范围不得自动扩大到安全或受专门法规管理的交通系统。
- **安全标志：** 优先查 ISO 7010、ISO 3864 系列及当地强制规范；形状、颜色和图形原件受控时直接复用或人工交接。
- **设备符号：** 优先查 IEC 60417、ISO 7000、IEC/ISO 80416 及产品标准；设备符号不得冒充公共信息或安全标志。
- **屏幕适配：** 从已批准原件适配到显示器时，保持 referent 与关键结构，另证光学尺寸和宿主状态。
- **测试方法：** 公共、设备或安全 claim 需要时查 ISO 9186 系列或辖区指定方法；本 Skill 不自行发明“合规通过线”。

找不到权威全文、许可或批准人时，记录未知并返回 G0/G1；不得根据搜索缩略图重画、根据相似外观声明标准，或把环境不可用误写成标准没有能力。

## 5. 画布、家族与光学尺寸

分别记录路径数学边界、描边外边界、像素/物理生产边界和感知边界。网格只帮助复现，不证明视觉质量。

| Concern | 稳定规则 | 允许的有据例外 |
| --- | --- | --- |
| 画布 | viewBox、有效区、基线、方向与视觉中心 | 圆、尖角和长对角线光学越界 |
| 线与曲线 | 主次线重、cap、join、曲率和节点质量 | 交汇、微缩连接和指针补偿 |
| 正负形 | 目标重量、孔洞和填充率 | 极密/极疏对象的感知补偿 |
| 视角/动作 | 一致视角、箭头和遮挡语法 | referent 只有换视角才可辨 |
| 变体 | 明确的 style、semantic state、direction、optical size | 真实消费者不需要则不创建 |
| 治理 | stable ID、版本、弃用与别名 | 已发布接口的受控兼容映射 |

### 光学检查

- 在实际 1× 尺寸检查主轮廓、孔洞、端点、交汇、方向和视觉中心，不以放大矢量代替。
- 只有几何确实针对尺寸发生受控差异，才称 `small`、`regular` 或其他光学母版；同一路径缩放只是导出尺寸。
- 小尺寸可放大孔洞、减少交汇、缩短次线；大尺寸可恢复细节，但不得改变 referent。
- 图形尺寸与点击/触控容器分别记录；放大容器不证明图形通过小尺寸检查。
- 描边与填充若都需要，应作为同义但独立校准的资产；填充版重新分配剪影和孔洞，不机械填黑描边。
- 反白通常是消费颜色；只有材料扩散、强光或负形闭合造成真实几何差异时，才建立 reverse optical variant。

家族检查最圆、最方、最密、最疏、最长对角线、最小孔洞和最高风险语义。统一的是感知重量与可复现语法，不是机械同面积、同圆角或统一容器；每个例外都记录原因和适用资产。

## 6. 主型专项检查

### UI 图标

- 先查项目库和宿主平台库；已有语义、许可和方向行为满足合同则复用。
- 记录图形尺寸、基线、文字间距、主题、高对比、RTL 和禁止镜像项。
- `hover / focus / pressed / selected / disabled` 通常由宿主组件拥有；只有图形承担新的语义时才产生资产变体。
- 图标按钮的可访问名称来自消费实例；sprite ID 或 SVG `<title>` 不能独自证明控件命名正确。

### 公共信息

- 把符号与箭头、文字、编号、地图和安装位置作为部署系统验证，不把单枚图形当作完整导视。
- 检查距离、角度、高度、速度、遮挡、逆光、低照度、反射、污损、老化与语言背景。
- “减少语言负担”不等于“跨文化天然理解”；证据只能覆盖命名受众与条件。

### 安全与运营

- 先判定是注册安全标志、运营命令、设备状态还是普通信息；四者不能因视觉相似合并责任。
- 注册或强制形态默认复用并保留标准颜色/形状组合，不为品牌统一重画。
- 新颖高风险语义在目标用户和责任人证据完成前只作为候选，并保留文字、确认、声音、灯光或触觉冗余。
- 重点记录“危险读成正常”“执行相反动作”“误把故障当确认”等方向性错误，而非只统计笼统正确率。

### 设备符号

- 区分设备部件、功能状态、连接端口、包装信息和操作指令；查对应设备/产品标准。
- 在真实面板尺寸、材料、背光、磨损、手套、视角和维护流程中验证。
- 屏幕图标从设备符号适配时保持原 referent；宿主告警逻辑与控制行为另由设备 concern 拥有。

### 品牌相关符号

- 身份标志由品牌领域拥有；本领域只接收批准母版，制作微缩、平台容器或品牌化功能图标。
- 品牌化功能图标先保功能识别，再有限迁移端点、曲率、切口或节奏；不得把主标塞入每枚图标。
- 商标近似、品牌授权和应用商店规范需要对应责任人；设计检查不冒充法律清查。

### 状态、动效与图标字体

- 动效记录 `from → to`、触发、取消、终态、循环条件、静态替代和 reduced-motion；真实播放器与宿主数据绑定都要验证。
- 图标字体仅在消费者确实要求时采用；记录 glyph map、私用区、基线、hinting、fallback 和文本替代，避免把字体作为默认包装。

## 7. 母版、导出与消费者

一个 concern 只能有一个 authority owner，但同一系统可由不同原生母版分别拥有语义、几何、状态或发布配置。代码、SVG、矢量 GUI 文件、组件库或字形源都可能成为母版，条件是可编辑、可审计、确定性重建并具有同版光学证据；压缩 path 仓库、截图和导出副本不能仅凭格式成为母版。

母版与导出至少检查：

- 可编辑构造、节点、布尔原件、复合路径、孔洞、fill rule、方向和受控例外；
- stable ID、viewBox、层名、组件属性、光学尺寸、主题/样式、弃用和别名；
- 导出前后的引用、mask/clip/paint server、透明背景、`currentColor`、命名与 hash；
- 从权威母版到 SVG、sprite、组件、原生 asset、字体、动效或物理文件的可复验 transform；
- 最终消费者真实导入，不用 specimen、文档或 Gallery iframe 代替。

消费者证明分两类：

1. **资产消费者：** 包可导入、公共接口稳定、主题/RTL/状态/基线/裁切正确、可访问责任明确。
2. **人类消费者：** 命名人群在声明任务与环境中看见、理解或行动；风险决定是否需要独立用户或现场 coverage。

两类都需要时不可互相替代。任何几何、语义、构建或导出变化产生新 `build_hash` 后，旧像素、review 和 promotion 不自动继承。

### 最终消费者与证据边界

先从 `final_consumer_record` 生成证据矩阵；每项证据只回答自身 concern，不能因都能显示图形而互相替代。

| 证据 | 能证明 | 不能证明 |
| --- | --- | --- |
| 浏览器 DOM/SVG | Web 中实际导入的节点、viewBox、ID、引用、可访问名称与结构关系 | CSS 解析后的外观、最终光栅像素、原生平台/打印/物理消费 |
| computed-style | 指定浏览器、主题和状态下解析后的尺寸、颜色、display、transform、方向与继承 | 其他 renderer 的实现、用户理解、物理材料与现场表现 |
| 目标 renderer | 合同指定浏览器、原生 runtime、播放器、固件、PDF/RIP 或设备在确切版本和尺寸下的最终像素/帧 | DOM 语义、跨 renderer 等价、实体生产或目标用户理解 |
| 实体样张 | 同版生产文件在声明材料、工艺、尺度、光照、距离、角度、磨损或背光条件下的最终验收 | 数字接口正确、其他批次/工艺、法规符合或超出样张条件的现场有效 |

Web 是最终消费者时，浏览器可以同时承担 DOM/SVG、computed-style 和目标 renderer 三类证据，但仍须分别记录结构、解析样式与最终像素。非网页媒介中的 HTML viewer 只用于查看；其浏览器证据不能冒充目标 renderer，更不能替代实体样张。

数字交付记录目标 renderer 名称/版本、资产与构建 hash、尺寸/密度、状态和最终像素。物理交付记录生产文件 hash、批次或样张 ID、工艺参数、检查条件及照片/测量证据的 hash；最终验收失败按因果返回 G3 或 G4，不通过美化 Viewer 消除差异。

## 8. 失败信号与返回

| 失败信号 | 返回 |
| --- | --- |
| 主型、消费者或法规范围错误 | G0 路由与风险 |
| 语义、最近邻、冗余或验证计划不完整 | G1 合同 |
| 稳定误读、危险反向动作、referent 不成立 | G2 语义骨架/候选 |
| 闭孔、黑结、重量漂移、变体不同义、公共 ID 破坏 | G3 母版/导出 |
| 平台导入、RTL、状态、可访问名称或物理样片失败 | G4 消费者 |
| 标准、许可、运营或安全签认缺失 | G5 授权；不得自批 |
| 工具不可用 | 替代候选或 `human_handoff`，不是 capability gap |
| 仅作者检查却要求外部 claim | 补独立 role-matched coverage 或降低 claim |

保留未受失败影响的 authority、资产和 gate。不得通过增加页面、说明框、风格变体或未请求图标来掩盖证据缺口。
