按当前身份风险读取相关章节。本文件保存路由细节、比较模式、工艺检查和失效信号；动作权限与 gate 顺序以主 `SKILL.md` 为准，通用治理、渲染和 review 以共享视觉协议为准。

## 1. 路由、范围与 claim ceiling

### 1.1 工作模式

| 模式 | 起点 | 允许继承 | 停止条件 |
| --- | --- | --- | --- |
| `create` | 主体、事实、身份任务 | 只继承明确批准的上游事实/资产 | 请求范围的母版与证据成立 |
| `edit` | 同条件旧版基线与改动边界 | 未失效 gate 可带 owner、版本/hash、适用条件继承 | 改动成立且既有不变量未回归 |
| `govern` | 批准母版、版本、消费者与例外 | 身份策略和核心可继承 | 资产消费、版本和弃用关系可执行 |
| `diagnose` | 可复现症状与只读证据 | 可读取全部现有记录 | 根因、影响范围和返回位置明确；零写入 |

### 1.2 Scope 的最低 claim ceiling

| Scope | 可以证明 | 单独不能证明 |
| --- | --- | --- |
| `mark` | 一个字标/图形标/锁版在声明条件下成立 | 完整品牌系统、市场记忆、商标安全 |
| `core_identity` | 主要载体、角色和不变量共同成立 | 所有触点、治理和长期采用 |
| `application_system` | 已批准核心能被声明消费者稳定复用 | 核心本身优于其他结构、未测试媒介 |
| `architecture` | 主体、背书、联名和例外关系可被正确理解 | 未确认实体关系、所有未来子品牌 |
| `migration` | 声明范围内的新旧关系、共存和弃用成立 | 自动继承旧资产的法律与认知价值 |
| `dynamic_identity` | 静态权威、不变量、允许变化和回退成立 | 未测试运行时、任意数据或平台 |

主体类型只改变事实、语境、近邻和消费者，不自动决定形式。场所不必使用建筑符号，科技产品不必使用几何渐变，文化项目也不必使用实验排版。

## 2. 问题驱动的真实参考

### 2.1 四种参考职责

| 参考类型 | 回答什么 | 不应学什么 |
| --- | --- | --- |
| 类别近邻 | 当前类别哪些轮廓、字母、关系和隐喻已拥挤 | 类别默认色和默认符号 |
| 跨类别结构类比 | 相同的长名称、多语言、远距、层级或变化问题如何解决 | 案例的签名形式 |
| 耐久/迁移案例 | 哪些不变量被保留，版本如何共存和弃用 | 新方案发布图的表面风格 |
| 失败案例 | 何种自由度、例外或模板导致系统失控 | 把失败样式反向当禁用类别 |

看案例前先写当前结构问题。每个未决问题通常只需 2–4 个能改变决定的案例；新增案例不再改变结构、工艺或验收条件时停止。

### 2.2 参考记录

```text
reference_id / 名称 / 来源 / 日期或版本
实际查看的 frame、实物或母版
它回答的结构问题与真实约束
主要识别载体 / 不变量 / 允许变化
可迁移原则 / 已知代价
禁止复制的资产、字形、色板、构图和签名机制
本任务要验证的具体关系
```

内部研究只在许可范围保存必要证据，不整站抓取、重发作品或把公开品牌资产打包进交付。没有实际画面、实物或母版时，只能记为待核线索。

### 2.3 近邻 contact sheet

- 固定背景、视觉面积、颜色条件和真实目标尺寸；
- 显示真实名称与图形关系，不只挑最有利版本；
- 记录外轮廓、负形、字母结构、读序、层级和类别隐喻的碰撞；
- 若颜色承担核心识别，保留颜色比较；另做无色回退板，不把两者混为同一测试；
- 候选混入同一 sheet，随机顺序、中性编号，先观察再揭示来源。

该板只能发现当前集合中的明显碰撞，不能替代商标检索或真实用户识别研究。

## 3. 身份载体与不变量

| 载体 | 适合承担 | 常见失败 | 重点检查 |
| --- | --- | --- | --- |
| 名称/字标 | 正式署名、读序、多语言确证 | 现成字体即成品、次语言装饰化 | 拼写、spacing、轮廓、语言视觉面积 |
| 图形标 | 极小、远距、跨语言或无文字归属 | 功能图标化、通用行业隐喻 | 轮廓、负形、近邻、回退 |
| 排版关系 | 内容密集、编辑性或制度型身份 | 换内容即失效、字体不可得 | 角色、许可、极端内容、替代方案 |
| 色彩关系 | 快速归属、分类或系列组织 | 只剩色相、对比不足、类别默认 | 角色、组合、色觉与无色回退 |
| 构图/容器 | 多单元归属、重复内容和架构关系 | 只在一张案例页成立 | 内容长度、比例、媒介和例外 |
| 图像/材料 | 文化、场所、产品世界和实体体验 | 素材决定风格、换图即换品牌 | 来源、处理规则、材料回退 |
| 声音/运动 | 广播、交互、空间和时间中的归属 | 装饰动效、随机变化 | 节奏、不变量、触发、静态/低动态回退 |
| 关系架构 | 母子、背书、联名和组合归属 | 每个单元另造 Logo、所有权误读 | 面积、读序、极端名称和禁止组合 |

每个载体记录：`priority / duty / invariants / allowed_variation / fallback / consumers`。一个系统可以分布式识别，但所有载体不能同时自称首要；删除任何不变量前先说明会损失什么归属信息。

## 4. 结构分叉与匿名比较

### 4.1 高影响结构分叉

- 名称主导、符号主导还是组合承担；
- 是否需要独立图形标；
- 多语言共现、切换还是按场景分配；
- 单一主体、背书、联名还是组合架构；
- 固定、响应、动态或生成式行为；
- 保留既有认知资产还是重构关系。

先用低成本探针解决影响最大的分叉，再测试第二个分叉；不要机械展开所有排列组合。一个方向已获历史证据时，反事实挑战可以保持低精度，但必须真实可见。

### 4.2 方向成立条件

一个方向必须能写成短结构指纹，不借品牌形容词，例如“两个字形共享一个连续负形”“主次名称由恒定面积关系组织”。如果只能说简洁、专业、高级、可信、未来或有温度，它不是结构指纹。

结构板只允许：真实或明确 provisional 的名称、核心载体、相同条件和中性编号。概念故事、摄影、材质、阴影、压纹、透视 mockup 和方向名在结构 gate 后才能出现。

### 4.3 比较方法

1. **成对比较**：逐对说明哪个在具体标准上更成立以及付出的代价；
2. **名称替换**：判断结构是否只是可无损套用的模板；架构型/制度型系统还要结合其他载体，不能仅因可迁移性判死刑；
3. **特征消融**：去掉所谓特征，观察身份是否受损、改善或不变；
4. **近邻盲排**：先报告碰撞，再读来源和解释；
5. **未来情境**：用新的名称长度、层级、媒介或行为检查是否必须发明第二套语言。

不使用“记忆性 87 分”或把多个弱项平均成一个总分。`must_pass` 失败直接淘汰；`compare` 保留整体判断和不确定性；`external` 不由作者补结论。

## 5. 核心工艺与两类剥离测试

### 5.1 支撑层剥离观察

- 主要身份载体仍然在场，故事、方向名和案例包装被移除；
- 可见关系能用短句复述，而不是靠箭头或长解释指出；
- 与固定近邻相比没有明显同构或类别符号退化；
- 视觉重心稳定但不僵硬，特征自然进入结构而非外挂；
- 去掉一项无职责装饰不会让作者的全部理由坍塌。

### 5.2 回退鲁棒性观察

只覆盖真实风险：单色、反白、极小、远距、低精度、受限材料、替代字体、静态或 reduced-motion。记录保留了哪些不变量、牺牲了什么以及回退版本的使用边界。不要要求回退版伪装成完整体验。

### 5.3 核心工艺

| Concern | 可直接检查 | 仍需整体判断 |
| --- | --- | --- |
| 名称与语言 | 拼写、读序、法定/背书关系、错误拆词 | 主次语言是否具有恰当的视觉权重 |
| 轮廓与负形 | 开口、交叠、堵塞、极小尺寸存活 | 结构是否集中、有张力且不过度制造怪异 |
| 字形与间距 | sidebearing、kerning、基线、重复节奏 | 权威、活力、温度或其他角色是否相称 |
| 光学关系 | 视觉中心、黑白面积、笔画/端点一致 | 稳定与生命力是否平衡 |
| 版本关系 | 不变量、允许变化和非法组合 | 不同版本是否仍像同一主体 |
| 近邻区别 | 当前集合的轮廓、字母和机制碰撞 | 区别是否值得长期持有而非首次噱头 |

核心工艺技术正确是下限，不自动等于身份成立。反之，区别也不能补偿难读、错误归属或不可复制。

## 6. 架构、响应与动态身份

### 6.1 品牌架构

先建立真实实体数据和关系语义：owner、endorser、partner、descriptor、series。用最长/最短名称、多语言、多个伙伴、未知单元、正常/极端/例外/禁止组合测试面积和读序。不要默认每个层级需要新标志，也不要用字号大小偷偷改变所有权。

### 6.2 响应式身份

每个版本记录目标条件、保留不变量、允许删减、切换阈值和回退路径。响应不是整体缩放，也不是任意删元素；消费者应能从同一 authority 选择版本。

### 6.3 动态或生成式身份

明确静态权威、时间/状态不变量、可变参数、边界、触发条件、非法输入、节奏和确定性复现。动态必须承担识别工作，不能只是粒子、随机移动或换色。提供静态、低动态和目标运行时回退；具体实现交给相应介质 companion。

## 7. 最小系统证明

每个资产族建立：

```text
consumer / real task / inherited invariants / content extremes
medium or production risk / authoritative owner / maintainer
pass evidence / stop condition / known limitations
```

选择性质不同的风险，而不是固定模板数量：小尺寸与远距、最长与最短内容、多语言与背书、密集与极简信息、数字与实体、静态与动态、正常与异常组合。只有 brief 实际承诺的条件才进入证明集。

遮住 Logo 后，应用可以在自身领域仍然优秀；这只说明消费者做得好。去掉消费者后，核心仍须拥有自己的身份证据。若应用需要重新发明排版、色彩、图像或行为才能有归属，返回载体或系统规则。

## 8. 各范围的最小交付契约

| 范围 | 最小但完整的品牌内容 |
| --- | --- |
| 标志/字标 | 唯一可编辑母版、主版本、真实需要的紧凑/单色/反白版本、目标尺寸、光学校正、输出映射、权利状态 |
| 核心识别 | 标志/字标契约、主要载体与不变量、字体/色彩/语言角色、响应规则、最小版式或图像原则、风险驱动消费证据 |
| 应用系统 | 已批准核心、每个资产族的消费者/任务/维护者、真实内容与极端条件、资产依赖和不同风险的使用证明 |
| 品牌架构 | 实体数据、所有权/背书/合作关系、正常/极端/例外/禁止组合、长短名称和语言测试、关系模板 |
| 焕新/迁移 | 旧资产盘点、必须保留/可演化/弃用/未知、同条件新旧比较、共存期、文件映射和弃用规则 |
| 动态/生成式 | 静态权威、不变量、参数/边界/触发、非法输入、首中末状态、静态/低动态回退、可编辑时间或程序源 |

这些是各范围在工具包骨架之上的追加合同。任何范围的交付底线都是
[工具包骨架](kit-skeleton.md)规定的档位文件夹与至少一帧品牌示例；用户只请求其中一部分时，
`applications/` 不扩展到未授权触点，但基础工具目录不因此省略。

## 9. AI 失效信号

### 9.1 普通结构被故事抬高

- 行业图标、首字母盒、圆、箭头、叶片、火花、无限环或通用轨道直接充当独特性；
- 更换名称和行业后，形式与解释仍可无损套用；
- 现成字体转轮廓后称为定制字标，只加一个切角、断笔或连字；
- 多个方向只换字体、颜色、圆角、切口和故事；
- 一段说明同时声称连接、平衡、精密、开放、成长和未来。

这些形式类别并非禁用；它们在作为无证据默认答案或补偿弱结构时触发返回。

### 9.2 提案包装掩盖核心

- 独特性只在渐变、发光、玻璃、金属、压纹、摄影或动效中出现；
- 只展示巨大主图，没有目标尺寸、正面、同条件或回退证据；
- 用多张同构 mockup 证明一个未通过的身份关系；
- 规范页充满概念标题、编号网格、细线、角标、灰色微文案和无职责留白；
- 用网页、包装或产品 UI 的精致程度反向证明品牌核心。

### 9.3 伪系统与伪专业

- 为完整感增加无消费者的纹样、图标、辅助色、模板和门户；
- 每个触点重造一套字体、网格、色彩或图像语言；
- tokens、manifest、文件数量、SVG 后缀或软件截图被当作品牌质量；
- 响应版本只是缩小/删除，动态版本只是随机移动/换色；
- 商标、母语、文化或生产未验证，却声称最终可注册、可量产或一定易记。

## 10. 自审边界与失败返回

### 10.1 SELF_REVIEW_ONLY

| 作者可以直接确认 | 需要相称的独立或外部角色 |
| --- | --- |
| 当前文件可编辑、母版与导出映射明确 | 商标可注册、无法律近似 |
| 当前测试尺寸、单色、反白和像素结果 | 市场中独特、无提示记忆 |
| 拼写、显式语言关系和变体规则 | 母语文化联想和真实识读 |
| 与指定近邻的可见碰撞 | 完整市场范围的区别度 |
| 当前消费者是否引用批准资产 | 组织采用、供应商量产和长期维护 |

作者先列反证和失败项，再列优势；最终解释使用“可见形式 → 身份任务 → 当前证据 → 未验证事项”。不得把“我能解释”升级为用户、法律或市场事实。

### 10.2 返回表

| 症状 | 返回位置 |
| --- | --- |
| 主体、名称、语言、所有权或权利不稳 | 事实与阻断项 |
| 无法说清谁认出谁、靠什么认出 | 身份策略与载体 |
| 参考只形成风格 moodboard 或近邻选错 | 问题驱动研究 |
| 方向同构、靠故事/颜色/效果区分 | 结构探索 |
| 支撑层剥离后没有可见指纹 | 结构探索 |
| 曲线、读序、间距、目标尺寸或回退失败 | 核心工艺；若改变不变量则回结构 |
| 触点比核心更有身份、各自重造语言 | 载体或最小系统 |
| 母版不可编辑、输出不可复现或 authority 不清 | 工具与 handoff |
| 外部识读、商标、文化或生产检查失败 | 返回最早能解释该失败的事实、结构或工艺 gate |
