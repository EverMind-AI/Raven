# 数据可视化领域模式与检查

本参考保存数据可视化的关系、状态和检查模式。先按主 `SKILL.md` 确定读者问题、数据状态、
view model、编码和工具，再从这里选择与当前结论风险相称的检查。专业工具选择另见
[工具能力档案](tool-profiles.md)。

## 1. 任务模式与 claim 风险

| 模式 | 初始状态必须回答 | 交互职责 | 常见失败 |
| --- | --- | --- | --- |
| 探索 | 数据覆盖、当前范围、质量状态和可比较关系是什么 | 提问、筛选、刷选、比较假设并保留总体上下文 | 预写唯一结论、隐藏过滤、只展示有趣子集 |
| 解释 | 读者无需操作即可看到什么有边界的证据 | 补充细节、切换合理对照、核对原值 | 标题替代证据、关键关系藏在 hover 或后续状态 |
| 监测 | 当前状态、基准、时间窗、新鲜度和可能动作是什么 | 切时间、定位异常、下钻并返回 | KPI 卡片墙、陈旧数据像实时、阈值无来源 |
| 出版 | 哪个版本、版面、分辨率和复现链是权威交付 | 可选导航不能破坏打印或静态阅读 | 只保存截图、导出与母版数值不一致 |

按 claim 生成验证计划，而不是套固定测试数量：

| Claim 风险 | 必须增加的领域证据 |
| --- | --- |
| 原值查找、单一描述比较 | schema、状态语义、独立复算、尺度/坐标和目标介质读数 |
| 聚合、率、指数、排名或筛选结论 | selection manifest、分母/权重、ties、mutation、多投影对账和敏感性 |
| 区间、模型、预测或异常判断 | 方法/版本、假设、训练与评估边界、区间含义、校准或回测、主题专家角色 |
| 因果、高影响处置或规范性建议 | 研究设计、识别假设、替代解释、风险披露和角色匹配的独立 coverage |
| 交互探索、BI 或持续监测 | view state、查询/指标权威源、新鲜度、空错过期、权限/过滤、导出与重开 |

## 2. 问题—证据矩阵

每个主问题登记一行：

```text
问题 / 观测单位 / 选择集 / 人群与时间 / 指标与单位
关系 / 主编码 / 比较基准 / 质量状态与不确定性
初始状态 / 必要交互 / 精确读数入口 / 允许 claim / 禁止推断
```

一个主视图只承担一个首要关系。多视图可以形成概览—比较—细查、证据序列或监测共视，
但不得因字段很多就平均铺成面板。标题中的每个关系必须能指向实际 mark、scale 或注释。

## 3. 关系与候选表达

| 关系 | 数据前提 | 候选表达 | 必须披露 |
| --- | --- | --- | --- |
| 类别量级或排名 | 同单位、同范围、排序规则稳定 | 点、条、小倍图 | 单位、排序时点、ties、缺失和选择集 |
| 相对基准偏离 | 零点、目标或参考值有领域意义 | 偏离点、发散条、区间 | 基准来源、方向、容差和截断 |
| 两时点变化 | 同观测单位配对成立 | 哑铃、斜率、端点或变化列 | 起终点、绝对与相对变化、缺配对 |
| 连续时间和事件 | 时间间隔、时区和缺期明确 | 折线、阶梯、区间带、小倍图 | 频率、缺测、修订、平滑和事件来源 |
| 分布 | 样本级观测或足够统计量 | 原始点、ECDF、直方、箱线/小提琴 | `n`、权重、分箱/带宽、离群规则 |
| 估计与不确定性 | 中心值和区间语义明确 | 区间点、误差条、带或分布 | 区间类型、水平、方法和样本设计 |
| 多变量共同变化 | 变量属于同一观测单位和兼容时间窗 | 散点、hexbin、等高线、分面 | 重叠、变换、聚合层级和模型假设 |
| 部分与整体 | 组成互斥、分母明确、闭合可验证 | 堆叠条、100% 堆叠、小倍图 | 总量、分母、残差、unknown 与可加性 |
| 流向或转移 | 来源—去向—权重和守恒成立 | 流量矩阵、alluvial、Sankey | 方向、守恒、重复计数、过滤和缺失流量 |
| 数据网络 | 边本身是观测且任务明确 | 邻接矩阵、节点—边、弧图、分层布局 | 边定义、方向、权重、孤立点、布局种子 |

饼图只适合少量互斥部分的粗略读取；精确比较改用共同基线。词云、3D 柱、体积、装饰图标
和无标尺气泡不能替代可比较的量值编码。

## 4. 数据状态必须端到端传播

状态在数据层定义，并传播到 view model、标题、图、表和导出；渲染器不得临时猜测。

| 状态 | 数据模型 | 图形 | 摘要/计算 | 表格与导出 |
| --- | --- | --- | --- | --- |
| 真实零 | `value=0` + observed/confirmed | 基线标记或真实零长度 | 正常纳入 | 数值 0 与状态并存 |
| 缺失/未知 | null + reason/status | 断点、空位或明确缺失，不置零/连线 | 排除并报告覆盖 | null、reason、status，不导出成 0 |
| 不适用 | null + not_applicable + 领域理由 | 与缺失使用不同标记/说明 | 不进入不适用计算 | 保留原因，不自行转零 |
| 抑制 | null + suppressed | 不反推、不显示伪精确值 | 报告抑制范围 | 状态与披露规则同行 |
| 估计 | value + method/version + 可选区间 | 估计符号、线型或区间 | 按预先规则纳入并披露 | 值、方法、版本、上下界 |
| 低可靠性 | value + reliability evidence | 保持可见并直接警示，不只降低透明度 | 限制排名/摘要或做敏感性 | 值、证据和质量标记 |
| 异常值 | 原值 + 诊断状态 | 保留并解释或显示有记录的处理 | 不静默删除/winsorize | 原值与处理并存 |
| 临时/修订 | value + release status/version | 可区分状态和更新时间 | 标题措辞随稳定性收敛 | 版本、修订日和抓取日 |

组成字段缺报按以下顺序处理：

1. 有独立权威总量且组成互斥时，可计算有语义的 unknown residual，并标成未知段。
2. 没有独立总量时，不把已知部分重归一化为 100%；改为已报告量或停止该行组成图。
3. 若问题明确限定“已报告部分中的份额”，建立新派生字段和新分母名称，不能沿用总体标题。
4. 缺失会改变排序、摘要或结论时，阻断整个证据单元，而不是只隐藏一段。

## 5. 变换、统计与选择

- 选择规则在看结果前可预设时应冻结；结果导向的编辑选择必须披露为探索性。
- 记录候选全集、纳入/排除、覆盖与外推边界；案例集不能被写成概率样本或总体排名。
- 百分比与百分点分开；相对变化同时保留基准绝对值和零分母策略。
- 均值、率、分位数、中位数和指数只在原始观测或足够统计量存在时重算。
- 复杂抽样保留权重、分层、聚类与重复测量；不得套简单随机样本区间。
- 端点比较不证明中间路径；趋势、持续上升或结构变化需要相应时间证据。
- 观察性关系默认描述共同变化。因果措辞需要设计、识别假设、混杂处理和敏感性。
- 排名声明记录未舍入值、ties、缺失排除、排序时点和选择集版本。
- 标题数字、图、表、下载不得各自实现公式；统一从版本化 viewModel 派生。

## 6. 编码、尺度与注释

- 精确量值优先共同位置和共同基线，其次长度；面积、角度、色彩承担次级关系。
- 条形与面积比较通常从零开始；点和线可使用非零 domain，但必须披露范围并检查误读。
- 对数用于倍数关系并处理零/负值；`symlog`、标准化、指数化和自由尺度都要解释可比边界。
- 分面、筛选和时间比较默认保持可比尺度；自由尺度只支持形状比较，并在每面重复范围。
- 不给非零值统一最短像素，不用隐藏断轴、裁剪或准确数字为失真的长度编码兜底。
- 颜色类型服从定类、顺序、连续或发散语义；发散中点必须有领域意义。
- 一个强调通道承担一个可复述职责；颜色之外用位置、文字、形状、线型或纹理冗余。
- 次要数据仍须可读；不要用接近背景的浅灰把总体上下文抹掉。
- 注释锚定可见 mark、事件、阈值或异常；来源、单位、状态和关键限制保持正常可读。
- 双轴默认不采用；确需使用时证明两个映射各自可读、关系未被任意缩放制造。

## 7. 交互、监测与派生输出

- 交互只加入会改变问题答案或检查路径的动作，并保留当前范围、选中量、清除、返回和分享状态。
- hover 与键盘焦点提供等价详情；静态结论不依赖 hover，Canvas 不作为唯一语义表面。
- 刷选/筛选后保留总体上下文；解释视图不允许任意筛选继续沿用原结论标题。
- 监测信号同组给出当前值/状态、基准、时间窗、新鲜度、趋势/变化和阈值来源。
- 空态区分没有记录、筛选为空、尚未到达、加载失败和数据过期；失败不得继续标成当前。
- 导出明确是原始快照、当前明细、当前聚合还是图像；当前 view state 必须同行记录。
- SVG、PNG、PDF、数据文件或 dashboard bundle 都要从母版重建并单独重开，核对单位、字体、
  状态、尺寸、筛选和代表值；格式不是越多越好，只交付合同需要的投影。
- 响应式不是等比缩小：当 mark、标签或尺度在目标上下文失去任务能力时，返回关系与编码重新选择表达。
- 复杂图提供短目的、结构化长描述或精确语义表；不要把所有数据点塞进一个 `aria-label`。

## 8. 压力与 mutation 计划

从 claims 和变换实际生成 fixture，至少覆盖会改变结论的状态：

- 解析：引号、空 token、区域格式、非法数、字段漂移和加载失败；
- 身份：重复键、缺记录、额外实体、错粒度和不兼容 join；
- 量值：真实零、负值、极端值、最小差异、零分母、单位错配和非有限值；
- 质量：missing、suppressed、estimated、provisional、revised 与低可靠性；
- 组成：缺项、超额、残差、负份额和不闭合；
- 视图：筛选为空、排序变化、当前状态下载、长标签、最密和最疏状态；
- 介质：合同中的最小/典型/最大上下文、打印或嵌入、字体替换和无 hover 输入。

每个 fixture 断言：能否进入 viewModel、各投影如何呈现、允许哪些结论、失败应回到哪一步。
存在解析、聚合或派生的数据产物不能把核心 mutation 记为 N/A；真正无运行时数据的固定图形，
可用独立复算、坐标证明和重开验证替代。

## 9. 诊断与失败返回

| 症状 | 优先检查 | 回到哪一步 |
| --- | --- | --- |
| 标题声称图中没有的关系 | 标题到 mark/scale/annotation 的映射 | 读者问题或关系与编码 |
| null 看成 0、缺口被连线 | typed state 与 viewModel 传播 | 数据状态或 view model |
| 小变化在目标尺寸等长或消失 | domain、像素映射和表达能力 | 关系与编码 |
| 排名像总体但样本不明 | selection、ties、缺失与覆盖 | view model |
| 图、摘要、表和下载数值冲突 | 数据 owner、公式和当前 view state | view model 与派生 |
| 使用成熟工具却仍像手画假图 | 原生模型、master 和导出是否真正拥有实现 | 工具选型与采用 |
| Canvas 能看但辅助技术无证据 | 语义表面、键盘路径和精确值入口 | 工具或交互 |
| dashboard 像实时但数据已旧 | freshness、刷新、错误与 stale 状态 | 数据状态或完整状态 |
| 视觉漂亮但任务失败 | 读者任务、范围和第一证据 | 读者问题或代表视图 |
| 导出与当前筛选不一致 | view state、export manifest 和重开 | 派生与导出 |

先修语义最早出错的步骤；颜色、阴影、圆角、标题或 tooltip 不能修复数据关系错误。

## 10. 相邻领域边界

- 地理位置只是类别标签时不自动画地图；投影、边界、路径、空间邻接或距离为主时转地图领域。
- 网络边表示测量关系且任务是统计比较时保留在本领域；表达系统组成或控制流时转技术图解。
- 图表嵌入内容网站或编辑出版物时，本领域拥有数据 truth，宿主领域拥有阅读序列和版面。
- 查询、告警、权限、处置和持久化成为主循环时，产品领域拥有工作流，本领域拥有图形投影。
- 操纵参数主要为了理解机制而非分析观测数据时，交互解释器可能是主领域。
