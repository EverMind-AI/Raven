# ANTI-SLOP-CHECK.md 账本格式

只记会改变像素的决定，一条一处，短句。

## 条目格式

```
## <组号> <病名> · <高|中>风险
- 位置：<成品文件>，<画面中的区域>
- 症状：<一句可见的事实>
- 修改：<改了哪个源文件的哪一处，改成什么>
- 复核：<重渲染后亲眼看过哪张成品，看到什么>
```

规则：

- 症状写看到的事实，不写意图或解释。
- 修改写具体动作，不写"已优化""已调整"。
- 复核必须发生在修改之后、重新渲染之后；写看的是哪一张、看到什么，不写"已确认"。
- 已路由但终态未命中的组，只写一行 `## <组号> <病名> · 未命中`。

## 终态全局扫描

交付前在账本末尾加一节：

```
## 全局扫描
- 看过：<成品清单或 contact sheet>
- 新命中：<组号，各自按上面格式补条目> 或 无
```

## 示例

```
## P 配色模板 · 高风险
- 位置：finals/print/overview_a2.png，整张底色
- 症状：五张 A2 和十张社媒图四角都是同一暖白，照片开窗嵌在纸上
- 修改：master/overview.html 背景层换成 image_generate 外延图 assets/generated/bg-workbench-ext.png，删掉 .paper 容器
- 复核：重出 overview_a2 与 watch_a2，底色随主视觉变为暗木色，纸窗消失
```
