# 插画与视觉场景模式

本文件保存领域判断模式，不规定统一画风。先在主 Skill 锁定主子型与当前 gate，
再读取相关部分；模式用于形成或诊断画面，不是必须全部生产的检查清单。

## 1. 子型路由

| 请求的主要价值 | 主子型 | 首要画面问题 | 不承担 |
| --- | --- | --- | --- |
| 回应文章、封面或公共议题 | 编辑插画 | 可见观点、语境、版位与留白 | 文章排版系统 |
| 把感受或抽象关系变得可见 | 概念插画 | 现实锚点、隐喻对应、理解顺序 | 精确流程或数值 |
| 捕捉正在发生的事件 | 叙事场景 | 主动作、阻力、结果、见证和环境反应 | 无关系的人物陈列 |
| 建立人物、生物或群体身份 | 角色/群像 | 剪影、身体逻辑、表演和关系 | 无需消费的完整资产库 |
| 建立地点、时代或生态 | 环境/世界观 | 地标、尺度、气候、通行与生活痕迹 | 建筑施工精度 |
| 观察物件、食物、植物或动物 | 物件/自然主体 | 轮廓、连接、材质、尺度和观察角度 | 技术剖面或伪科学标注 |
| 用时间变化承担叙事 | 动画场景 | 表演、节奏、镜头、连续性和运动层级 | 交互状态或游戏规则 |
| 用规则或形状表达非具象主题 | 抽象/程序化 | 规则、参数边界、变化和停止条件 | 随机装饰 |

出现严格步骤、完整部件、数值编码或真实坐标时，改路由到图解、数据或地图领域。
出现 campaign 套系、页面母版或交互状态时，由相邻领域拥有外层系统，本领域只拥有插画资产。

## 2. 从真实案例学习机制

为每个参考记录其真实来源、消费者、媒介和可核验版本，然后只抽取：

- 构图如何制造第一视线与停顿；
- 人物、对象和空间如何形成可见关系；
- 明度、色彩、边缘和材质如何分配职责；
- 原生媒介留下什么可编辑结构与制作痕迹；
- 同一机制在哪些题材、比例或消费者中会失效。

Create/Edit 可在授权范围内用代表性局部重建机制，再与参考并排找差距；原创迁移时更换命题、
对象、构图和表面语言。Diagnose/Audit 只核对既有参考、重建记录与画面，不创建重建稿、缩略、
导出或新 hash。只保存链接、风格标签或“像某位艺术家”不构成方向证据；不得同时复制同一
作品的构图骨架、角色设计、标志配色和表面处理。

## 3. 构图与叙事骨架

### 单核与回声

一个主体或关系承担最高面积、对比或锐度，次级形态以方向、尺度或间距回应。
适合编辑、概念和物件主体；回声必须强化主命题，不能变成等权阵列。

### 双主体张力

用距离、朝向、遮挡、尺度或光差表达冲突、依赖、错位或共鸣。两者之间必须存在
可见关系，而不是分别摆出两个漂亮姿势。

### 动作接力

视线、手势、姿态、道具或光沿主体传递。每段都有接触或因果；装饰线、箭头和颜色
不能替代身体与对象的真实交接。

### 框中事件

以门窗、洞口、枝叶、镜面或前景物集中一个瞬间。框景不能误切脸、手、关节、
动作端点或关键道具。

### 分层全景

用前景遮挡、主事件和远景语境建立地点与尺度。边缘、对比、细节密度和空气透视
随空间职责变化，不要求所有区域同等清楚。

### 并行舞台

同一空间可有多个片段，但先定义主事件、次事件和环境反应，再用结构、光或动作连接。
规则格子、相同房间和同权人物会把叙事退化成说明卡片。

### 负空间悬置

以低频空间包围小主体，建立孤独、等待、宁静或敬畏。主体仍须能被快速找到；
信息不足和构图松散不等于极简。

### 尺度转换

并置宏观环境与微观对象，或让现实对象承担抽象关系。保留足够的物理锚点，
避免只有超现实奇观却没有可解释命题。

## 4. Scene logic 检查

### 动作与因果

为每个必要事件写：

`主体 → 动词 → 对象 → 阻力/约束 → 可见结果 → 环境或他人反应`

如果主体只能写成“站着、看着、摆着”，它通常不承担事件。关键道具应在来源、
交接/使用和结果中保持身份、尺度与材质连续。连续画面还要检查动作方向、位置、
服装、伤痕、光源和时间线。

### 人体、接触与受力

- 先看纯剪影：姿态、年龄/体型、角色和动作是否可区分；
- 从可见肢体末端反向追到关节和所属身体，标出遮挡前后；
- 手掌、手指、脚底、身体和道具必须真正接触，不以近似相邻代替；
- 从被抬、推、拉、坐、站或悬挂的重量反向追到承重面；
- 头、胸腔、骨盆和脚的方向要支持动作，瞳孔不能挽救相反的身体语言；
- 风格化可以改变比例和形状，不能取消归属、接触和重力逻辑。

没有人物或身体动作不是 claim 时，记录子型理由并跳过；不要制造无关检查项。

### 空间

- 先锁镜头、地平线、消失关系和尺度参照，再增加表面细节；
- 用重叠、尺度、边缘、明度、色偏和细节密度共同区分前中后景；
- 检查脚底、地面、入口、通道、家具、建筑与投影是否属于同一空间；
- 主观空间可以故意违背透视，但违背方式必须一致并服务命题；
- 复杂空间若在二维草图中反复漂移，先做可编辑 blockout，不用雾和颗粒掩盖。

### 光与色

先用灰度决定值组与焦点，再分配颜色职责。为每个重要光源写出来源、方向、衰减、
受光面、投影和反光；动机光可以局部例外，但同一表面不能同时服从矛盾光源。

颜色应来自环境光、对象局部色、材料、时代语境、角色身份或信息层级。把明度极值、
饱和极值和锐边集中给重要关系。随机色、统一高光、通用渐变和全局电影滤镜不能修复
构图或空间。

## 5. 媒介模式

| 媒介模式 | 它应留下的原生痕迹 | 常见失真 |
| --- | --- | --- |
| 结构化矢量 | 可编辑路径、语义组、色板/符号、可控轮廓和画板 | 机械曲线、统一描边、滤镜堆叠 |
| 分层数字绘画 | 画层/组、蒙版、笔刷与边缘层级、原生像素 | 无结构涂抹、糊边、噪点遮错 |
| 拼贴/摄影合成 | 链接或嵌入资产、蒙版、变换、光色与颗粒统一 | 来源不明、边缘割裂、相机不一致 |
| 3D 辅助/场景 | 尺度、对象、相机、灯光、材质和 render passes | 默认材质、塑料感、穿插和无 art pass |
| 生成图辅助 | 候选 lineage、输入来源、模型/版本、可控修正边界 | 解剖/文字错误、重复纹理、来源断裂 |
| 动画场景 | 镜头、图层/节点、时间线、曝光/关键帧和声音关系 | 只有转场、无表演、时序不连续 |
| 程序化图形 | 参数、规则、确定性构建和可解释变化 | 用代码便利替代造型能力 |

媒介混合时，每个 concern 仍只有一个 authority；为资产、相机、绘画、合成和时间
分别画出派生边。通用噪点、默认阴影或随机渐变如果不能由材料、光或叙事解释，应删除。

## 6. 跨比例与系列

先列每个消费者必须保留的主体、关系、动作端点、叠字区和观看距离，再决定：

- **安全裁切：** 原构图有充足余量，关系和焦点不变；
- **局部重排：** 改变位置、尺度或留白，但保留同一事件；
- **重新构图：** 画幅改变了叙事顺序，需要新的镜头或动作安排；
- **独立变体：** 消费者任务不同，不能宣称是同一构图的适配。

系列固定的是形状逻辑、身体比例、边缘、空间、值组、色彩职责、光线、材质和细节密度，
不是每幅的布局。角色、物件和环境的连续性由共享母版或明确 authority 传播，不靠目测重画。

## 7. Claim/risk 证据选择

| Claim 或风险 | 最小领域证据 | 失败返回 |
| --- | --- | --- |
| 首读叙事 | 无标题目标尺寸观察，记录实际读到的主体/动作/关系 | 构图或合同 |
| 构图层级 | 缩略、灰度、目标画幅和真实叠字/裁切 | 构图 |
| 人体动作 | 剪影、关节归属、接触/受力局部和整图对应 | Scene logic |
| 空间可信 | 镜头/地平线/遮挡/承重证据；需要时 blockout | Scene logic 或工具 |
| 光色一致 | 灰度、光源—受光—投影链和关键材质 | Scene logic |
| 媒介真实性 | 原生母版结构、制作痕迹和导出对应 | Tool/master |
| 跨比例重构 | 每个消费者的独立画面与保留关系对照 | Variant build |
| 动画连续性 | 首中末帧、关键动作区间、镜头/时间线和实际播放 | Scene logic 或 Variant |
| 生成辅助可控 | provenance、风险局部、编辑链和修正后整图 | Tool/master |

证据数量服从 claim、风险和状态空间；不要把固定样本数写成普遍通过线。

## 8. 像素症状与优先修复

| 症状 | 常见根因 | 优先返回 |
| --- | --- | --- |
| 缩略只剩均匀小块 | 主体尺度和值组平均 | 构图 |
| 能见人物却说不出动作 | 躯干、手势、接触或对象不成立 | Scene logic |
| 人物像同一模板换色 | 剪影、比例、脸型和重心无差异 | Direction/Scene logic |
| 物件漂浮或身体穿插 | 承重、遮挡、投影或透视矛盾 | Scene logic |
| 环境像扁平布景 | 相机、尺度和深度线索同质 | Scene logic |
| 焦点与装饰一样响 | 极值和纹理平均分布 | 构图 |
| 光漂亮但不可信 | 来源、方向、衰减和投影不闭合 | Scene logic |
| 颜色像随机抽样 | 没有值组与颜色职责 | Direction/Scene logic |
| 拼贴来源互相割裂 | 相机、边缘、颗粒与光色未统一 | Tool/master |
| 3D 像默认资产展示 | 相机/材质未 art-direct | Direction/Tool |
| 生成图局部融化 | 风险结构未审或不可控 | Tool/master |
| 变体像机械裁切 | 焦点未重排、关系被切断 | Variant build |
| 动画只剩晃动 | 时间变化不承担叙事 | Contract/Direction |

修复后必须回到同一 claim、目标尺寸和消费者条件复验；局部修好不自动恢复整件 promotion。
