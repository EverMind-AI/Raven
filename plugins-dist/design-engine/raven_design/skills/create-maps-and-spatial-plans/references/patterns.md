# 地图与空间规划模式

本参考保存领域子型、空间模型、检查细则与失败信号。任务路由、工具分工和工作顺序以 `SKILL.md` 为准；工具能力档案见 `tool-profiles.md`。

## 1. 先确认它真的是空间任务

| 判断 | 主领域 |
| --- | --- |
| 用户必须依赖真实位置、邻接、方向、范围、边界或网络可达性 | 地图与空间规划 |
| 去掉几何仍主要比较数值、排名、趋势、分布或不确定性 | 数据可视化；地图只作空间索引 |
| 节点可任意布局，主要表达部件、因果、接口或流程 | 技术图 |
| 主要工作是长期搜索、编辑、调度和审批对象 | 产品/工具界面；空间引擎仍由本领域负责 |

交通线网或室内路径即使不按比例，只要真实站序、换乘、level、方向或到达关系决定行动，仍属于本领域，并显式声明 `topological` 或 `indoor_multilevel`。地理轮廓不能把统计排名伪装成地图任务。

## 2. 空间发布包的 concern

一个逻辑发布包可以有多个原生母版，但下列每个 concern 只能有一个 authoritative owner：

| Concern | 最小对象 | 常见派生物 |
| --- | --- | --- |
| 来源与观测 | source、许可、日期、精度、适用范围 | 来源注记、更新提示 |
| 基础空间 | feature、geometry、CRS、unit、level、status | 地图图层、边界、底图 |
| 网络与连接 | node、edge、direction、restriction、connector | 路线、服务区、步骤 |
| 分析与方案 | method、parameter、run、result、assumption | 数字、分类、覆盖、比较 |
| Claims | claim、evidence、disposition、expiry | 标题、标签、警告、说明 |
| 制图 | style、label rule、legend、orientation、scale mode | 屏幕/印刷地图 |
| 介质布局 | viewport/page/installation contract | HTML、SVG/PDF、标牌 |

派生物只能消费上游 concern。显示层移动入口、重写距离、手补路线或新增统计类别时，应返回相应 owner，而不是把导出物升级为新事实源。

## 3. 定位与参考地图 `reference`

适用于“我在哪里、目标在哪里、周边关系如何”。

- **模型**：范围、控制点、地名层级、当前观察位置、目标、连续道路/路径和方向基准。
- **构图**：先读当前位置/目标，再读主要边界、路径和可靠地标；区域概览与近场决策需要不同尺度时使用双层视图，不压进一张图。
- **方向**：固定标牌可按安装位置选择 heads-up；跨设备和通用印刷常使用 north-up。任何旋转都同步方向提示与文字。
- **关键检查**：当前位置必须绑定可辨认的站位、入口或楼层；控制点落在预期位置；比例尺只在具备尺度语义时出现。
- **失败信号**：用建筑中心代替实际观察点、地名层级混乱、范围无法支撑任务、方向与现场视线无关。事实错误回来源与空间模型，层级错误回制图视觉。

## 4. 导航与路线 `route_network`

路线主记录至少保留：

```text
anchor → snap_connector → network edge sequence → route segment
       → cost/constraint ledger → instruction → displayed geometry
```

- 起终点吸附必须记录候选、方法、距离、连接几何、level、障碍穿越和审核状态；容差由来源精度、空间阻隔、交通方式和风险生成，不采用领域统一数值。
- 有向 edge 保留稳定 `(u,v,key)` 或等价 ID、几何、长度、方式、方向、restriction、开放/门禁和可达性属性；多条平行边不能按最短长度静默合并。
- 距离、ETA、步骤、箭头和显示折线从同一 route ledger 派生。需要人工修订时修改 master/ledger 并重算，不能只拉动 SVG 或文案。
- 指令绑定 route segment 和决策点；只在方向变化、入口、换乘、跨层或高风险处增加提示，避免箭头、编号和文字无差别叠加。
- 比较路线时展示真正影响选择的成本、限制与不确定性；单路线执行时压低未选路线，但不得隐藏必要的风险或失败结果。

路线 claim 递进：

| Claim | 最低证据 |
| --- | --- |
| “展示该路线” | 已提供路线与显示映射 |
| “计算路线” | 可复算网络、connector、edge sequence 和 cost |
| “最短/最快/最优” | 明确 objective/profile、候选范围、限制和独立复算 |
| “step-free/轮椅可达” | 路径级相关属性无阻断 unknown，并具备所需现场/专业 coverage |

## 5. 专题与分区 `thematic`

- **模型**：空间单元、指标/类别、单位、时间、分母、缺失与不确定性、分类方法和 source lineage。
- **编码**：连续量使用与量纲一致的顺序尺度；有真实中点才使用发散尺度；类别使用可区分的定性色。缺失不是零，范围外也不是无数据。
- **几何**：检查边界版本、空间连接、重叠/孔洞、多部件和海岸/裁剪效应；统计结果不能随显示概化而改变。
- **图例**：顺序、阈值和单位与分析一致；关键区域可直接标注，避免用户在大图例和地图间反复寻找。
- **跨域门**：统计变换、样本和不确定性由数据可视化领域验证；本领域验证空间单元、连接和地图表达。任一门失败都不能发布组合 claim。
- **失败信号**：任意分箱、缺失着零色、品牌色覆盖语义、专题层遮住任务地理、地图形状被当作统计因果证明。

## 6. 服务区与空间分析 `service_area`

```text
origin → legal connector → network/spatial model → cost/profile
       → reachable result → boundary/generalization → edge replay
```

- 明确区分网络服务区、欧氏缓冲、行政覆盖、插值面和经验范围；标题、图例和 claim 使用真实方法名称。
- 网络模型记录 mode、方向、转向、速度/阻抗、换乘、门禁、楼梯/电梯、河流/铁路等阻隔以及数据时间。
- 多阈值结果检查嵌套、孔洞、跨障碍、边界裁切和地图范围截断；多设施覆盖的重叠规则必须能解释。
- 验证点按风险和边界形态选择，在覆盖边缘内外、障碍两侧、网络断点和地图边缘复算，不使用固定样本数。
- 结果面只是计算派生；手工平滑不得改变可达节点或产生不存在的连接。
- **失败信号**：用圆冒充网络等时区、忽略不可达孔洞、路线成本与覆盖阈值异源、只看面是否漂亮。返回空间模型与分析。

## 7. 场地与空间规划 `site_plan`

- **模型**：边界、控制点、轴网、单位、标高、用途、限制、流线、版本和 `world_state`。
- 现状、拆除、保留、新建、临时和模拟状态必须分别编码并可追溯；proposal 不得覆盖 observed master。
- 行人、车辆、物流、应急和无障碍流线按任务建立网络或几何约束，检查交叉、回转、净空、坡度、出口和服务界面。
- 面积、容量、退界和冲突必须从权威几何计算；未经测量的概念布局只能声称方案关系，不能声称施工坐标。
- 技术底图保留必要线型、尺寸、轴号、标高和 revision；展示派生可裁剪细节，但不能改写边界和尺寸。
- **失败信号**：现状/方案混淆、共享角点不一致、视觉对齐代替坐标、饱和填充遮住边界或尺寸。依次检查来源、空间模型、分析和制图。

## 8. 楼层与室内 `indoor_level`

- 每层记录稳定 level ID、本地原点、轴向、标高、单位和与建筑/地理坐标的转换；没有控制关系时不得擅自套 EPSG。
- 门、走廊、墙、限制区、入口、房间和目的地保持对象语义；楼梯、电梯、坡道和扶梯使用成对 connector ID。
- 跨层路线在进入与离开连接器的两层都连续，并显式记录交通方式、方向、开放/门禁和可达性。
- 访客导视可压低家具和机电细节；设施、施工或安全交付必须保留相应专业图层，不把不同使用合同混成一张图。
- 应急疏散、消防和法定导向触发相应标准与合格 reviewer；普通室内地图不能外推这些 claim。
- **失败信号**：跨层直连、门不落在墙/走廊网络、室外入口与室内 portal 分离、平面截图冒充可编辑空间 master。

## 9. CRS、尺度、方向与几何检查

| 检查 | 通过条件 | 回到哪一步 |
| --- | --- | --- |
| 坐标类型 | geographic、projected、local planar 或 topological 已明确 | 任务与空间模型 |
| CRS/轴序 | source/analysis/display CRS、坐标顺序和转换可追溯 | 来源与空间模型 |
| 单位/基准 | 距离、面积、标高、时间及本地原点一致 | 来源与空间模型 |
| 几何 | 空、无效、自交、多部件、环、重叠与裁剪按子型处理 | 空间模型 |
| 拓扑 | 连通、方向、共享边、connector、level 与阻隔成立 | 空间模型 |
| 尺度 | 测量/比例结论使用合适分析方法；示意明确不按比例 | 分析与结论 |
| 方向 | north-up、heads-up、场地轴向或观察方向有任务理由 | 制图视觉 |

Web Mercator 适合常见屏幕显示，不自动适合精确测距或面积；角度坐标上的直线长度不能冒充米。本地平面即使封装为 GeoJSON也不会自动获得地理语义。

## 10. 制图表达检查

- 视觉顺序服从用户行动：当前位置/目标、活动路线或主空间对象、关键边界/限制、地名和次要背景。
- 风险色只承担危险、封闭、异常、未知或需确认；普通备选路线通过标签、终点、线型或稳定 active role 区分。
- 颜色之外使用形状、线型、纹理和文字冗余编码；去色后仍能区分关键类别与状态。
- 图例只解释用户不能从直接标签理解的符号；单位、时间、方法、缺失和“不按比例”等不能藏进低对比微文案。
- 标签按任务优先级避让路线、入口、边界和警告；先移位、引线、裁剪次层或改变范围，再考虑缩字。
- 删除不参与定位、分析或规划的装饰地标、纹理、阴影和 UI 卡片；但不要用“极简”删除必要地理上下文。

## 11. 介质派生检查

### 浏览器 / 现场采集客户端

- 地图 source、style、route/analysis 与文字从权威 owner 派生；DOM 或 Canvas 不能保留第二套手写空间事实。
- 每个真实图层、筛选、路线、楼层、时间和选择状态都同步更新地图、图例、文字、URL/状态语义和导出。
- 按用户任务验证缩放边界、最密标签、地图边缘、键盘/非指针访问、依赖与离线合同。
- 路线移动视图的首个有效上下文要让用户恢复起点、活动路线、终点和下一动作；实现方式由空间与任务决定，不规定固定组件或占比。

### Static / Print / Installation

- 静态输出独立包含任务标题、必要图例、方向、比例尺或“不按比例”、来源日期、单位、假设与限制。
- Print 从纸张毫米尺寸、方向、比例策略、观看距离、字体/矢量和设备合同开始；检查最终 PDF 的真实 MediaBox、字体、裁切和物理样张，不以网页截图代替。
- Installation 将地图方向、安装点、高度、视距、环境光和现场地标纳入合同；屏幕或手持 proof 不能替代安装 proof。
- 各介质可分别布局，但必须追溯同一空间/分析/claim owner；一个介质通过不能覆盖其他介质。

## 12. 公共、无障碍与安全声明

将视觉可访问性与物理可达性分开。`steps`、坡度、横坡、宽度、路面、路缘、门槛、门、电梯、门禁、开放和施工都是路径或入口属性；缺一项时按 claim 所需范围保留 unknown。

| 声明 | 必要 coverage |
| --- | --- |
| 公共到达/入口可用 | 当前来源、入口语义、路径连接；运营事实按风险需要现场或设施方确认 |
| step-free | 路径级台阶与跨层属性无阻断 unknown；必要现场 coverage |
| 轮椅可达 | 除台阶外还需适用的宽度、坡度、表面、路缘、门和设备证据 |
| 疏散/消防/安全 | 适用规范、权威底图、责任角色和合格专业 review |
| 测量/施工/产权/合规 | 对应资质、精度、版本、签审与法域证据 |

免责声明不能把已知限制变成 unknown，也不能把 unknown 变成安全。reviewer 只覆盖其角色有资格判断且绑定当前 build 的 claims。

## 13. 风险驱动验证计划

为每个 claim 写：可能失效方式、影响、权威 owner、机器检查、人工判断、是否需要用户/现场/专业 coverage、证据有效期和失败返回。覆盖数量由状态空间、几何边界、风险与介质决定，不按领域固定人数、固定阈值或固定截图数。

优先抽查：最强 claim、最长或最复杂路径、边界内外、跨障碍/跨层、最高标签密度、缺失/unknown、最小与最大尺度、最危险误读及每种介质的独立失败模式。

## 14. 诊断矩阵

| 症状 | 首查对象 | 回到哪一步 |
| --- | --- | --- |
| 点位整体偏移、镜像或尺度异常 | CRS、轴序、datum、unit、本地原点 | 来源与空间模型 |
| 路线穿墙、越河、离开网络 | connector、edge、方向、阻隔、mode | 空间模型与分析 |
| 距离/ETA 与显示线不一致 | route ledger、connector、取整和显示映射 | 分析与结论 |
| 服务区跨不可达障碍 | 方法、网络、阈值、孔洞、边缘回算 | 空间模型与分析 |
| 专题图结论随配色或边界版本变化 | 指标、分类、空间连接、缺失 | 来源与分析 |
| 楼层切换后路线断开 | level/portal/connector ID 与方向 | 空间模型 |
| 已知限制只出现在泛化脚注 | 结论与 segment 映射 | 结论表达 |
| 地图正确但难以行动 | 范围、层级、标签、决策点和风险语义 | 制图视觉 |
| Web、PDF 或标牌内容互相矛盾 | 派生方向和介质转换 | 空间模型与介质派生 |
| 工具只被提及、成品仍为手写第二套 | 实际工具使用与可编辑母版 | 工具选型与采用 |
