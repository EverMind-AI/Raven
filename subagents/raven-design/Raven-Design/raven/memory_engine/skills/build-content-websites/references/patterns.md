# 内容型网站领域模式

本文件只补充 D11 的领域路由、URL 生命周期、内容与媒体 provenance、发现和出版验证。共享状态、authority、tool-use、review 与 promotion 字段沿用治理契约，不在这里另造一套。

## 1. 领域路由

### 主领域判定

同时检查四项：主对象、用户职责、权威来源，以及删除独立内容身份与发现/阅读后会失去什么。

| 交付物 | D11 成立条件 | 转交或组合 |
| --- | --- | --- |
| 单篇出版物 | 一项可引用内容，有来源、日期、阅读承诺和稳定入口 | 只有海报/封面时转传播图形 |
| 小型静态站 | 多项内容有独立路由、集合入口和构建责任 | 组件复用本身不是 D11 |
| 出版/机构站 | 内容优先级、责任、更新和可信行动构成核心 | 登录不改变归属；反复业务操作转产品界面 |
| 文档/知识库 | 版本化答案、学习/查询路径和弃用关系构成核心 | 设计系统文档仍以设计系统为主域 |
| 目录/档案 | 稳定记录、字段、来源链、权利、发现和引用构成核心 | 以绘制/测量空间为主时转地图领域 |
| CMS 内容产品 | 非技术编辑的真实内容流程服务公开/用户侧内容 | CMS 后台本身的操作体验可由产品界面负责 |

内容站可以有搜索、筛选、付费墙、评论或一次性表单；这些控件不自动改变领域。反之，页面公开也不代表它是内容站。

### 两轴组合

| 组合 | 常见完整形态 | 不应自动添加 |
| --- | --- | --- |
| `frozen × single` | 专题、报告、一次性说明或单篇长文 | 集合、搜索、CMS、伪修订历史 |
| `frozen × collection` | 固定版本的小型出版物、目录快照 | 持续编辑角色、定时发布 |
| `frozen × search/faceted_relational` | 数据集或档案快照的可检索发行版 | 由“静态”推断低发现复杂度 |
| `maintained × single/collection` | 有负责人和更正/归档规则的内容站 | 多角色权限与审计 |
| `maintained × search/faceted_relational` | 持续更新的文档、目录或出版物 | 无证据的实时新鲜度 |
| `governed × 任一发现轴` | 真实 CMS/出版治理，发现能力按任务单独选择 | 由 CMS 推断一定需要搜索或分面 |

## 能力触发

| 能力 | 触发谓词 | 未触发时的诚实边界 |
| --- | --- | --- |
| 独立实体 URL | 内容需分享、引用、索引、深链或进入集合 | `single` 仍需稳定入口，但不伪造页面族 |
| 搜索 | 已知项查找是核心、有限导航无法覆盖、内容持续增长或需全文/字段检索 | 用明确浏览入口，不放无效搜索框 |
| 查询 URL 恢复 | 查询需分享/书签/返回，或检索是关键路径 | 可不持久化轻量辅助查询，但要声明 |
| 分面与关系 | 用户需组合字段或跨实体导航，且字段/关系有受控语义 | 不用标签云冒充分面或关系图 |
| canonical | 同一内容有多个可访问 URL、语言/设备版本、参数页或转载 | 单一公开地址不为勾选项生成 canonical |
| redirect/迁移 | 已有入站 URL、slug/结构/域名将改变 | 新对象无旧地址时记录触发不成立 |
| 更正/归档 | 内容会更新、有信任/法律风险、存在多作者或现行/历史差异 | frozen 只声明固定版本，不伪造编辑流 |
| 媒体权利治理 | 第三方、UGC、授权期限、敏感或受限制媒体 | 全部原创仍保留作者与原件 provenance |
| 公开 SEO/结构化数据 | 公共搜索或机器消费是明确渠道 | 私有/离线内容不虚构抓取合同 |
| CMS/发布治理 | 非技术编辑、多角色、高频发布、审批、定时、权限或媒体复用 | Git/文件发布可满足较小 maintained 站点 |

## 2. 内容身份与事实模型

### 最小实体合同

按子型裁剪字段，不建立“未来也许会用”的万能 schema：

```text
identity: stable_id, kind, route_key
content: title, summary, body_or_fields, language
responsibility: author_or_owner, source, created_or_published, updated
state: publication_state, correction_or_archive_ref
discovery: collection, controlled_terms, relations
media: asset_refs
```

- `stable_id` 不随标题、栏目或展示 slug 改变。
- 首次发布、最后更新、生效、事件和历史年代是不同语义，不合并成一个日期。
- 作者、编辑、责任机构、来源提供者和权利方按实际职责区分。
- 未知、约略、推定、争议和缺失值显式建模，不能由模板猜成精确值。
- 关系必须有方向和语义，如“属于系列”“替代”“引用/被引用”，不能只有“相关推荐”。

### 内容 provenance

每项权威内容至少可回溯：`source_ref`、责任 owner、采集/创作方式、时间、适用范围、许可或使用依据、已知不确定性、修订记录。外部数据应保留原始标识和获取日期；作为新闻、研究、客户或馆藏事实呈现的演示／合成内容必须在内容语境内可见说明，不能冒充事实。只建立世界或气氛、不承担事实 claim 的生成背景在 provenance 记录边界，不把制作说明印进页面。

用真实边界内容验证 schema：最长/最短标题、字段最全/最缺、最旧/最新、含不确定值、含关系和含受限媒体的对象。选择由 corpus 风险决定，不以固定数量代替覆盖。

## 3. URL 生命周期

### URL owner 合同

URL 权威 bundle 应同时管理：`stable_id → current_route`、历史 alias、redirect 状态、canonical 规则、语言/版本关系和终止原因。标题或导航变化不应静默改变实体身份。

| 变化 | 首选处置 | 必验行为 |
| --- | --- | --- |
| 标题变化，身份不变 | 保持 URL 或建立可追踪 redirect | 旧入站链接到达同一实体，无链式跳转 |
| 栏目重组 | 改导航关系；只有 URL 同时改变才迁移 | 集合、面包屑、内部链接和 sitemap 同步 |
| 内容被新版本替代 | 旧页保留状态与替代链接，或定向 redirect | 历史引用不会被首页吞掉 |
| 内容仍有历史价值但不现行 | archive 页面保留身份、日期和现行入口 | 搜索/导航清楚区分现行与历史 |
| 法律/安全原因必须移除 | 按合同使用 410、受限说明或批准的 redirect | 缓存、索引和下游副本有处置记录 |
| 路径从未存在 | 404 提供范围和恢复入口 | 不把所有未知路径重定向首页 |

只有触发重复地址时才定义 canonical。筛选、排序和分页 URL 是否 canonical/noindex，取决于其是否代表可引用集合；不要把所有查询参数一律压到首页。

迁移先导出旧 URL 与真实入站规则，再建立逐项映射、冲突和无法迁移清单。验证直接请求、刷新、相对/子路径 base、redirect 状态与链长、404/410，以及生成链接与权威映射的一致性。

## 4. 更正、修订与归档

`frozen` 记录发行版时间、作者/来源和 build；不得借一个“更新时间”暗示持续维护。

`maintained` 至少定义负责人、复核触发、更正与普通更新的区别、归档/弃用条件、旧 URL 处置和可回退发布。更正记录应保留时间、改动性质、责任和受影响内容，不能用新日期覆盖历史。

`governed` 只在真实系统中证明：角色/权限、预览、审批、定时或受控发布、审计、回滚、备份、恢复和监控。静态表单、硬编码角色或成功 toast 不是治理证据。

| 事件 | 页面必须表达 | 历史必须保留 |
| --- | --- | --- |
| 普通更新 | 当前适用内容与更新时间 | 依风险决定差异摘要 |
| 实质更正 | 更正性质和发生时间 | 原发布信息、责任和变更记录 |
| 撤回 | 不再可信/可用及原因范围 | 身份、撤回事件和替代来源 |
| 弃用 | 当前不推荐及迁移入口 | 适用版本、替代内容和截止时间 |
| 归档 | 历史状态、原始语境和现行入口 | 原日期、来源和稳定引用 |

## 5. 媒体 provenance 与派生

原件或批准的资产清单拥有 provenance；优化器和页面只生成派生物。清单至少记录：稳定 asset ID、原件 hash、作者/提供者、来源、拍摄/创作时间、许可与期限、允许的编辑/裁切、敏感性、alt/caption 职责、派生规则和下线条件。

- 事实图像说明对象与正文关系；装饰重现不得冒充证据。
- `alt` 传达图像信息，caption 处理归属和语境；纯装饰图使用空替代文本。
- 裁切不得删掉关键人物、对象、文字或比较依据；任何修改应可从 derivative 回溯原件和 transform。
- 授权到期、原件替换或权利变化时，能够定位所有派生物与消费页面。
- 媒体缺失时保留诚实文字记录，不用通用占位图制造假完整。

## 6. 发现合同

### `single`

证明稳定入口、清楚标题/来源/日期、页内结构和必要的来源/行动链接。目录只服务长内容定位，不冒充站点导航。

### `collection`

每个实体可独立到达；集合规则可解释且来自内容字段。按真实关系选择编辑优先级列表、时间索引、字段表、图文网格或分组目录，不默认卡片墙。详情应返回集合或给出有依据的下一步。

### `search`

先写查询合同：精确标题、正文/主题词、别名或旧术语、拼写/语言边界、宽泛词和零结果。定义索引字段、分析器、权重、排序、更新时机与新鲜度上限。结果提供标题、类型、命中语境及任务相关的版本/日期/集合；实际 index 从内容与检索合同重建。

### `faceted_relational`

分面使用受控字段和值，计数与结果来自同一查询；支持清除单项/全部、空态恢复、适用分页、分享/刷新/前进后退和详情返回语境。关系显示来源和语义，不能以相似标题替代。分页或连续加载都需保留可达 URL、位置和总量语境。

任何 discovery 轴都要测试新增、修改、归档或删除一项权威内容后，集合、关系和适用 index 是否按新鲜度合同更新。索引失败必须回到同步/transform，不得手改结果缓存。

## 7. 跨介质出版与消费者验证

### 跨介质构建前

- 校验 ID 与适用 route 唯一、必填与枚举、关系目标、日期语义、内容来源、媒体引用和权利状态。
- 确认至少一个人类阅读/查看消费者，以及各消费者的目标介质、renderer/client/device、语言、公开/私有范围、分发限制和回退方式；feed/API 只作为附属 consumer。
- 对 edit/migrate 建立字段、分类、URL、资产和状态差异，不猜补未知值。

### 跨介质构建后

- 从权威 owner 重建当前交付，核对内容身份、事实、日期、更正/归档状态、媒体 provenance、呈现映射和输出 hash。
- 在目标消费者中运行适用的浏览、真实查询、零结果、宽泛结果、分面计数、分页和返回语境；检查 index 对当前内容 hash 的新鲜度。
- 在目标 renderer/client/device 检查最长标题、长文、缺字段、宽媒体、阅读/解析、错误与回退；正文和可信元数据不得因呈现转换而丢失或失真。
- 所有消费者取得当前 `build_hash` 的最终验收；视觉消费者另取得同一 hash、目标尺寸和关键状态的最终像素。非 Web 的浏览器预览只作辅助证据。

### 仅 Web 最终消费者

以下检查只有在人类最终消费者或合同交付确为 Web 时启用；非 Web 项写 `N/A + 介质理由`，不得为了执行本表制造浏览器外壳：

- 确认目标 base、origin、公开/私有范围、抓取策略、部署限制和回退方式。
- 直接打开入口和代表深链；验证刷新、404/410、redirect、静态资产、内部链接和适用 sitemap/feed。
- 适用时验证每页 title/description/language、canonical、结构化数据和 robots 行为与可见事实一致。
- 检查 DOM/可访问树中的标题层级、地标、键盘路径、焦点、文字放大、图像替代、表格/代码和错误反馈。
- 从当前构建检查合同内每个目标环境；正文与可信元数据不得被降成灰色微型字。
- 在目标发布 URL 和实际嵌入/顶层容器执行链接、资源、缓存/失效、回退和消费者检查；本地开发服务器成功不等于目标发布成立。

### 出版轨迹

`maintained` 应实际演示一次更新或更正到目标消费者和历史的传播；`governed` 应由真实角色路径演示预览、审批/发布、失败、回滚或恢复。只观察当前呈现不能证明发布历史。

## 8. 诊断返回表

| 现象 | 优先检查的 owner/transform | 返回位置 |
| --- | --- | --- |
| 页面事实互相冲突 | 内容事实 owner 与 schema | 内容合同 |
| 旧链接失效或循环 | URL bundle 与 redirect transform | URL 生命周期 |
| 搜索漏项或陈旧 | 检索合同、同步事件、内容 hash | 索引 transform |
| 分面计数不同步 | 查询/聚合是否同源 | 发现合同 |
| 更新日期可信度不足 | 发布 ledger 与页面投影 | 发布历史 owner |
| 图片漂亮但不可核验 | 资产清单、权利与 transform | 媒体 provenance |
| CMS 看似可用但无真实写入 | invocation、角色和 revision evidence | 工具选择/流程 |
| 开发环境正常、目标路径失败 | base、构建输出与部署配置 | delivery transform |

最终判断来自当前权威内容经已证明工具链进入真实消费环境后的结果，而不是源码意图、文件齐备或 Viewer 标签。
