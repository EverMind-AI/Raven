# 行程方案 PPT 规范

文件编号 HL-MKT-SPEC-04，V4.2，2026年9月25日起执行（V4.1：每日安排写入调研查证的信息；店外信息须能在调研结果中找到。V4.2：随模板 V3.0 与品牌规范 V2.0 更新页面对应与设计引用）。方案 PPT 是客人保存、转发给家人的报价方案，以余位确认和电子合同为准。设计层面另见《品牌与内容设计规范》HL-MKT-GUIDE-07，版式以《方案 PPT 模板》HL-MKT-TPL-08 为准，每一页都从模板里对应的页开始。

## 1. 格式

- 一个 .pptx 文件，16:9；以店里的方案 PPT 模板为底制作，不另起版式；
- 全部中文；文件名为"海岚旅行-报价编号.pptx"；
- 不使用动画和切换效果；字体只用模板内置的两种。

## 2. 页序与每页内容

| 页 | 名称 | 必须包含 |
|---|---|---|
| 1 | 封面 | 模板自带的组合标志；"为某某准备的行程方案"，称呼用客人自己说的，没说时写"尊敬的客人"；目的地加晚数的大标题；日期、人数构成、产品档位；报价编号；小字"报价方案，以余位确认和电子合同为准" |
| 2 | 行程一览 | 产品名、目的地、出行日期（照客人说的写，不补年份）、晚数、人数构成 |
| 3 | 为什么是这条线 | 三条理由，每条对应客人自己说过的情况；亮点取自产品说明，不夸大 |
| 4 起 | 每日安排 | 第几天加日期；天数等于晚数加一；框架取自产品说明，写入调研查证过的具体线路、交通班次与时长、参考酒店（标明"以计调确认为准"），查证事实注明来源；内容多的一天用单日页，简单的几天用三天一页，每页不超过三天 |
| 倒数第 4 | 费用明细 | 与最后一版报价单逐项一致：每人基础价、儿童基础价、加晚、附加项、全团总价、季节档、报价有效期；意外险单列；全团总价是全页最大的数字；定制游写"每人起价""全团起价"及"最终价格以规划通话确定" |
| 倒数第 3 | 包含与不含 | 各一个短列表，取自产品说明 |
| 倒数第 2 | 下一步与出行须知 | 经济游、舒适游：计调核实余位、1个工作日内发送电子合同、按出发日期适用的付款节点、出团通知书出发前3天发送；定制游：资深顾问2个工作日内致电规划。适用的安全提示；"天气、开放时间等以出团通知书为准" |
| 最后 | 联系我们 | "价格以海岚旅行现行价目表为准。海岚旅行 · 旅行社业务经营许可证 L-ZJ-CJ00318 · 杭州市西湖区保俶路118号 · 0571-8765 4321"；小字"本方案由海岚旅行AI数字顾问协助生成，以电子合同为准" |

可选页：章节开篇页可放在每日安排之前；方案对比、住宿、线路示意、行前清单、常见问题、图文页、重要提示、交通明细等，内容需要时插在每日安排之后、费用明细之前，都从模板里对应的页开始。可选页不替代上表的任何一页。

## 3. 不得出现

价目表以外的价格或与报价单不一致的数字；任何折扣或优惠字样；调研结果里没有的外部信息（交通班次、开放时间、门票、天气、酒店、餐厅）；未标明"以计调确认为准"的酒店名；内部备注、占位文字、模板里的示例文字；关于 PPT 是怎么做出来的说明（联系页的声明除外）。

## 4. 顾问质检清单

- [ ] 报价编号、各项价格、全团总价、季节档、人数构成与最后一版报价单完全一致；
- [ ] 所有外部信息都能在本次调研结果里找到，参考酒店标明以计调确认为准；
- [ ] 日期、晚数与每日安排的天数一致，日期未补年份；
- [ ] 称呼是客人自己说的；
- [ ] 页序与每页内容符合第2节，没有遗漏页；
- [ ] 以店里模板制作，符合《品牌与内容设计规范》，没有其中"不要这样"一栏的任何做法；
- [ ] 适用的安全提示已写入；下一步与产品类型、出发日期相符；
- [ ] 没有第3节的任何内容，没有模板示例文字残留；
- [ ] 文件名正确，无动画与切换效果。
