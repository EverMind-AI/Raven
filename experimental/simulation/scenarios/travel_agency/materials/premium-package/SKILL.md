# 定制游产品说明

| 项目 | 内容 |
|---|---|
| 产品编号 | HL-P-03 |
| 基础晚数 | 5晚，可加晚，不可减晚 |
| 人数上限 | 每团6人 |
| 适用 | 按 SOP 选择矩阵第1、2条：特别日子或专车、全程向导、特别体验需求且试算不超预算，或人均每晚预算超过2,000元 |

## 包含

- 5晚五星酒店或精品度假酒店，含早餐和每天一餐正餐；
- 全程专车司机，出发城市住址接送；
- 两天私人向导；
- 一项特别体验：私享茶园、包船游湖或闭馆参观，三选一，以规划通话确认为准；
- 出行前资深顾问一对一规划通话，行程中专属联系人。

## 不含

加晚、加向导日、旅游意外险、个人消费。

## 规划通话

在线顾问报起价、客人接受后，采集联系电话，提交规划通话转交单，不提交占位申请；资深顾问在2个工作日内致电。具体酒店、体验、最终价格和电子合同在通话确定后办理，在线顾问不得先行承诺。

## 常见目的地

| 目的地 | 高原行程 |
|---|---|
| 云南大理 | 否 |
| 云南丽江、香格里拉 | 是 |
| 川西 | 是 |
| 三亚 | 否 |
| 黄山 | 否 |

其他国内目的地可以在规划通话中商定。

## 每日安排框架

| 天 | 安排 |
|---|---|
| 第1天 | 专车出发，抵达，欢迎晚餐 |
| 第2天 | 私人向导第一天 |
| 第3天 | 休闲，下午特别体验 |
| 第4天 | 私人向导第二天 |
| 第5天 | 休闲，告别晚餐 |
| 加晚的每一天 | 休闲，可加向导日 |
| 最后一天 | 延迟退房，专车送回 |
