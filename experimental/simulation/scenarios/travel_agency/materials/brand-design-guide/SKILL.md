# 品牌与内容设计规范

文件编号 HL-MKT-GUIDE-07，V2.1，2026年9月25日起执行，市场部发布（V2.0：品牌视觉更新为纸白、墨、柿红；新增标志规范与"合格方案的设计语言"。V2.1：新增设计元素库）。本目录下的 `brand-kit.pptx` 是品牌手册，五页：标志、色彩与字体、审定图标、组件、合格方案的设计语言，和本规范一致。

海岚旅行的方案 PPT 要让客人一眼觉得"这是一家讲究的小店写给我的"：克制、安静、可信，像一封写得很用心的信，不像促销单。

## 一、标志

1. **组合标志**：左边是柿红方印，印里是反白的"岚"字；右边是"海岚旅行"字标，下面一行"HAILAN TRAVEL"，与字标左对齐。字标与方印用的是品牌字体的字形，已做成图形，不要用打字代替。
2. **用在哪里**：封面左上角用组合标志；内容页页脚左侧用小号字标；联系我们页用反白组合标志（深色底，方印保持柿红）。模板里都已放好，照用即可。
3. **留白与尺寸**：标志四周至少留出方印边长一半的空白；组合标志最小宽 30 毫米，方印单独使用最小 8 毫米。
4. **不要**：拉伸或旋转；改颜色；加阴影、描边、渐变；把字标换成别的字体重打；直接压在照片上。

## 二、色彩

| 颜色 | 色值 | 用在哪里 | 占比 |
|---|---|---|---|
| 纸白 | #FFFFFF | 页面底色 | 约七成 |
| 墨 | #1E2326 | 标题、正文；联系我们页的底色 | 约两成 |
| 岚灰 | #5E6F6B | 页名、日期标签、来源行等次要文字 | 少量 |
| 雾 | #F2F4F1 | 每日安排页"查证事实"栏的底 | 少量 |
| 线 | #D5DAD6 | 分隔细线 | 少量 |
| 柿红 | #D9531E | 方印、全团总价、步骤序号 | 不超过一成 |

柿红是全篇唯一的强调色，一页里只留给最要紧的一处；不用柿红写大段文字，不引入第七种颜色。

## 三、字体与字号

1. **只用两种字体**：标题用思源宋体（Noto Serif CJK SC）Bold；正文、标签、数字说明用思源黑体（Noto Sans CJK SC）。缺省时宋体用 Songti SC、SimSun，黑体用 PingFang SC、Microsoft YaHei。
2. **字号**：页面标题 28 至 32 磅，写结论；封面主标题 56 至 64 磅，写目的地和晚数；正文 14 至 16 磅，行距 1.3 至 1.4；页名与标签 12 至 13 磅，岚灰；来源行不小于 11 磅。
3. **同一页最多三级字号**；全团总价是全页最大的数字。

## 四、版面

1. 16:9。左右留白不少于页宽的 8%，上下不少于页高的 8%。
2. 十二栏网格，正文左对齐；同一页元素的左边缘对齐到同一条线；同类元素间距一致。
3. 内容页页脚一行：左侧小号字标，中间报价编号，右侧页码。封面和联系我们页不放页脚。
4. 分组靠留白和细线，不靠边框、底色块和卡片；宁可分页，也不把一页塞满。

## 五、内容规法

1. **一页一个核心信息。** 每页只回答一个问题，要点不超过三个，每个要点不超过三十个字。
2. **标题写结论，不写名词。** 行程一览写"几天几晚加这趟行程的节奏"这样一句话，不写"行程概览"；费用页写"几位全包多少元、意外险怎么算"，不写"费用明细"。页面上方的小页名可以保留。
3. **数字要让人放心。** 金额一律写"元"并用千分位，例如"9,400 元"；全团总价单独成行、字号最大；不写"约""左右"；定制游之外不写"起"。
4. **称呼贯穿始终。** 封面用客人的称呼，正文里需要时用"您"和客人的称呼，不写"用户""游客"。
5. **理由对着客人说。** "为什么是这条线"的每条理由都要落到客人自己说过的情况上（孩子多大、怕累、想看什么、有什么纪念日），不写放之四海皆准的套话。
6. **语气亲切专业。** 用陈述句，不用网络流行语，不用"超值""爆款""限时"这类促销词；全篇感叹号不超过一个。
7. **只说店里说得准的话。** 交通班次、开放时间、门票、天气、酒店只写调研同事查证过的，写在事实旁边并注明来源；没有查证的就不写，也不用"以实际为准"去填空。
8. **结尾要有下一步。** 最后两页必须让客人知道接下来会发生什么、需要他做什么。

## 六、合格方案的设计语言

| 要这样 | 不要这样 |
|---|---|
| 标题写结论：说出这一页要客人记住的一句话 | 标题写名词："行程概览""费用明细" |
| 一页一件事，要点不超过三个 | 一页塞满卡片、图标和胶囊标签 |
| 全团总价是全页最大的数字，用柿红 | 每个数字都做成大号数字卡 |
| 来源写在事实旁边，字号不小于 11 磅 | 满页"以实际为准"的灰色小字免责 |
| 没有合适照片就留白，用排版、线路和图标分出层次 | 装饰线、圆圈、渐变、阴影、3D、图标拼贴、表情符号、水印 |
| 照片只用调研找到并注明来源的实拍照片，除封面外不超过半页 | 卡通、剪贴画、明显由 AI 生成的人物，或来源不明的图 |
| 客人确认过的出发地、日期、人数、价格一字不差 | "待确认""示例""占位"或模板里的样例文字留在成品里 |
| 页型跟着内容走：每天一页或三天一页，行数按实际删减 | 每页都是"大标题加三张圆角卡片" |

## 七、设计元素库

店里审定过的通用元素，任何目的地、任何客人都能用；方案里只用这里有的，不另找。

1. **品牌母题**：一条柿红路线穿过等高线纹理，表达"替客人把路排好"。只出现在封面、章节开篇和联系我们页，模板里已放好，不改动、不挪到内容页；它不代表任何真实地点，不能当地图用。
2. **审定图标**：Tabler 线性图标（MIT 许可），墨色或岚灰，0.22 至 0.42 英寸；柿红只用于安全提示。图标只用来标明信息的种类，一行、一项最多一个，不拿来装饰，不用填色、彩色图标和表情符号。

| 类别 | 图标与含义 |
|---|---|
| 交通与线路 | train 高铁、火车；plane 航班；car 用车、接送；bus 大巴；ferry 轮渡；walk 步行；route 当天路线；map_pin 地点 |
| 住宿与餐食 | bed 住宿；tools_kitchen_2 餐食；cup 茶歇、休息；building_arch 古迹、景点；ticket 门票；camera 照片；mountain 山地；beach 海岛 |
| 时间与天气 | calendar 日期；clock 时间；hourglass 有效期；sunrise 早起、日出；sun 天气；umbrella 雨具；map_route 产品线路；compass 自由活动 |
| 同行的人 | users 人数；baby_carriage 儿童；old 长者；wheelchair 无障碍；heart 纪念日、偏好；headset 顾问；phone 电话；message 消息 |
| 办理与付款 | checklist 核实余位；contract 电子合同；credit_card 付款；receipt 报价单；currency_yuan 价格；shield_check 保险；id 证件；bell 出团通知书 |
| 提示与清单 | alert_triangle 安全提示；info_circle 说明；first_aid_kit 药品；backpack 衣物、随身；luggage 行李；check 包含；x 不含；star 推荐 |

3. **组件**：

| 组件 | 用在哪里 |
|---|---|
| 方印 | 标志、页脚、头像 |
| 日期章（方印的描边形） | 每日安排页的第几天与日期 |
| 线路（站点加连线，住宿地用柿红） | 行程一览、线路示意、当天路线 |
| 时间轴 | 一天之内的先后 |
| 流程线 | 下一步：先后与时间点 |
| 查证事实（图标、事实、来源） | 交通、住宿、门票等外部信息 |
| 客人原话（柿红引号） | "为什么是这条线"的理由 |
| 价格块 | 全团总价，全篇最大的数字，只此一处用柿红大字 |
| 提示框（雾色底加安全提示图标） | 安全、高原等必须留意的事 |
| 勾选清单 | 行前清单 |

4. **单页版式**：模板里除必备页外，还有方案对比、住宿、线路示意、行前清单、常见问题、图文页、重要提示、表格页，内容需要时从对应的模板页开始，不自己另画。

## 八、自检三问

交付前，顾问对照三问看一遍：这一页只讲了一件事吗？客人会信这个数字吗？把店名遮住，还像海岚旅行做的吗？
