# 舒适游产品说明

| 项目 | 内容 |
|---|---|
| 产品编号 | HL-P-02 |
| 基础晚数 | 4晚，可加晚，不可减晚 |
| 人数上限 | 每团8人 |
| 适用 | 人均每晚预算超过500元、不超过2,000元的客人（按 SOP 选择矩阵） |

## 包含

- 4晚四星酒店含早餐，有景观房时优先安排（不保证）；
- 出发城市往返高铁一等座或国内航班经济舱，含两程接送站；
- 第1晚合作餐厅晚餐一次；
- 半日私人向导一次；
- 行程方案 PPT 一份，行程中紧急联系电话。

## 不含

其他餐食、景区门票、水疗、旅游意外险、套房升级。

## 目的地清单

| 目的地 | 高原行程 |
|---|---|
| 大理 | 否 |
| 丽江 | 是（第3天一日游为玉龙雪山） |
| 厦门鼓浪屿 | 否 |
| 黄山 | 否 |
| 三亚 | 否 |

## 每日安排框架

| 天 | 安排 |
|---|---|
| 第1天 | 出发、接站、入住，合作餐厅晚餐 |
| 第2天 | 半日私人向导，下午自由活动 |
| 第3天 | 推荐一日游线路，可代订车辆 |
| 第4天 | 自由活动 |
| 加晚的每一天 | 自由活动 |
| 最后一天 | 早餐后送站返回 |

套房升级只在客人提到纪念日或主动要求时推荐，价格见价目表。
