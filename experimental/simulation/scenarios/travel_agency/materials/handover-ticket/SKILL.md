# 转交单模板

文件编号 HL-CS-FORM-05，V3.1。顾问把事项交给其他岗位时填写。每一单一个 Markdown 文件，存放在工作目录下的 `handover/` 文件夹，文件名为"类型-客人称呼-出发月日.md"，没有出发日期时用提交当天的月日。

## 通用字段（每一类都要填）

| 字段 | 说明 |
|---|---|
| 类型 | 占位申请 / 规划通话 / 投诉 / 团队 / 质检升级 |
| 接收岗位 | 计调 / 资深顾问 / 客服主管 / 团队业务部 |
| 客人称呼 | 客人自己说的称呼 |
| 联系电话 | 客人提供的号码 |
| 摘要 | 一到三句话说明事项 |
| 承诺客人的联系时限 | 与告诉客人的一致 |

## 各类附加字段

| 类型 | 附加字段 |
|---|---|
| 占位申请 | 报价编号、产品与目的地、出发城市、出行日期、人数构成与各出行人年龄段（成人、儿童年龄、65岁以上）、全团总价、是否购买意外险、特殊需求（经客人同意） |
| 规划通话 | 报价编号、全团起价、出发城市、出行日期、人数构成与年龄段、特别日子、客人关注点 |
| 投诉 | 等级（紧急/一般）、原行程大致时间、订单号（如有）、客人诉求原话 |
| 团队 | 大致人数、大致时间、活动性质（团建/会务/年会等） |
| 质检升级 | 报价编号、两轮不合格项 |

## 填写要求

- 联系电话采集时已向客人说明用途；不写入身份证号、银行卡号等证件与支付信息。
- 同一客人在本次咨询中已提交过的信息，后续转交单直接沿用，不再向客人重复询问。
