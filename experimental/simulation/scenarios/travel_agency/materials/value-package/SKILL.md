# 经济游产品说明

| 项目 | 内容 |
|---|---|
| 产品编号 | HL-P-01 |
| 基础晚数 | 3晚，可加晚，不可减晚 |
| 人数上限 | 每团8人 |
| 适用 | 人均每晚预算不超过500元的客人（按 SOP 选择矩阵） |

## 包含

- 3晚经济型酒店或精品青旅双人间，含早餐；
- 出发城市往返高铁二等座或经济舱；单程超过6小时的，首末日为交通日；可加购高铁一等座升级；
- 第2天上午半日徒步导览一次；
- 目的地城市交通卡一张；
- 行程方案 PPT 一份，行程中紧急联系电话。

## 不含

午餐和晚餐、交通卡以外的门票、旅游意外险、接送站（可加购）。

## 目的地清单

| 目的地 | 高原行程 |
|---|---|
| 厦门 | 否 |
| 成都 | 否 |
| 西安 | 否 |
| 桂林 | 否 |
| 黄山（屯溪） | 否 |

## 每日安排框架

| 天 | 安排 |
|---|---|
| 第1天 | 上午高铁出发，入住；下午按交通卡地图自由活动 |
| 第2天 | 上午半日徒步导览，下午自由活动 |
| 第3天 | 使用交通卡周边一日游 |
| 加晚的每一天 | 自由活动 |
| 最后一天 | 延迟退房，下午高铁返回 |

每日安排只写到框架这一层，不写具体餐馆、景点开放时间或价格。
