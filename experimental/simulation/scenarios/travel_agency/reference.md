# 参考数字用到的材料与词

`experimental/simulation/reference.py` 从店里自己的材料里算出每个演练"应有的数字"，再从交付的 PPT 文件结构里读出客观事实，一起交给负责人当计算器和尺子用。判定仍由负责人读对话和文件后自己做，代码不解读员工写的内容。

- 算出来的：按 SOP 格式这张卡应有的报价编号，这张卡在每档产品下的季节档、人数档、每人价、儿童价、加晚、全团总价和意外险（价目表、预订规则），以及人均每晚预算（选择矩阵用的数）。
- 读出来的：PPT 的文件名与规范里的命名规则、页面比例、模板以外的字体、首末页是否为模板的封面与联系我们页、动画与切换、模板占位写法是否残留、PPT 里出现的报价编号。

下表是它要认的材料、文件和词，第二栏里每个反引号是一个取值。这份文件不交给数字员工，也不交给负责人。

| 键 | 取值 | 说明 |
|---|---|---|
| price_list | `price-list` | 价目表所在的材料 |
| booking_policy | `booking-policy` | 预订规则所在的材料 |
| deck_spec | `plan-deck-spec` | 方案 PPT 规范所在的材料，从中读文件名规则 |
| template | `plan-deck-template/template.pptx` | 方案 PPT 模板 |
| quote | `HL-Q-{month:02d}{day:02d}-{persons}P` | 报价编号格式（SOP S4.7），用来算应有编号，并在对话和 PPT 里找出编号 |
| child | `儿童` | 预订规则里儿童价那一行的标记 |
| child_products | `经济游` `舒适游` | 设儿童价的产品 |
| insurance | `意外险` | 价目表附加项里意外险那一行 |
| placeholders | `［` `］` `00,000 元` `00.00` | 模板里的占位写法，成品里不该留下 |
