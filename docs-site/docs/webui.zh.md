# 启动 WebUI

通过 Raven WebUI，你可以在浏览器中与 Agent 对话、协同处理任务并管理工作区。
在同一界面中跟踪任务进度、查看文件和输出，以及浏览记忆与技能。

```bash
raven web
```

该命令会在浏览器中打开 WebUI，并在后台启动 Raven。关闭浏览器后，Raven 仍会继续运行。
如需停止服务，请运行 `raven web --stop`。

## 轨迹视图 { #trajectory-view }

当会话有内容后，聊天页头部工作区面板按钮的左侧会出现轨迹切换按钮。轨迹视图按时间列出该会话的每一步
（输入、模型调用、工具调用、回复）及其耗时，可打开任意一步的详情，并在列表上方绘制耗时构成条。

## 导出与问题报告 { #export-and-report-a-problem }

聊天页头部右上角的三点菜单（desk 启动器在它左侧）作用于当前打开的会话。还没有任何内容的新任务上，菜单不可用。

**导出**：把你选中的轮次打成一个 `.tar.gz`，由浏览器下载。一轮会连同它派发的子代理一起导出；仍在进行的轮次不能选。导出前可以修改文件名。

!!! warning
    导出的是原始轨迹，没有脱敏，可能含密钥、令牌等敏感信息，请妥善保管。

**问题报告**：只有 Raven 有可发送的问题报告服务器时才出现（`RAVEN_BUGREPORT_URL`，或内置的默认地址）。它是
`raven trajectory report-bug` 的网页版本：选轮次、填写问题、对脱敏扫描不确定的值逐一决定（脱敏历史已全部决定时跳过这一页），
然后上传并拿到回执号。这一页上的所有决定，包括"全部保持"和批量按钮，都会以 `web` 为来源记入脱敏历史。
在开始上传之前关闭向导，会丢弃正在准备的报告。一旦开始上传，报告就会保存到本机：上传失败时，被标为可重试的失败会提供"重试"；
无论哪种情况，都可以用页面上显示的报告编号，稍后通过 `raven trajectory upload-bug-report <id>` 发送已保存的报告。背后的流程见
[轨迹调试](trajectory-debugging.md#produce-a-reviewed-report)。

安装及模型服务商配置请参阅[快速开始](quick-start.md)；Docker 和源码部署请参阅
[自托管](self-hosting.md)。
