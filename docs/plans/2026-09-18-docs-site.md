# Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move self-hosting, web-UI launch, the command reference and the repo layout out of both READMEs into a bilingual MkDocs site published on GitHub Pages, leaving Quick Start in place.

**Architecture:** A new `docs-site/` tree holds Markdown only; `mkdocs-material` plus `mkdocs-static-i18n` build English at `/` and Chinese at `/zh/`. A GitHub Actions workflow builds on every pull request and deploys from `main`. HTML is never committed. Five guards pin the properties the move would otherwise break silently.

**Tech Stack:** Python 3.12, `uv` (the only permitted package manager), MkDocs, `mkdocs-material`, `mkdocs-static-i18n` >= 1.0, GitHub Actions, pytest.

**Spec:** `docs/specs/2026-09-18-docs-site-design.md`

## Global Constraints

- Branch base is always `origin/main`, never local `main` (AGENTS.md 2.2).
- Branch names are `<type>/<snake_desc>` (AGENTS.md 2.1).
- Commit messages: Conventional Commits, English, ASCII only, header <= 100 chars (AGENTS.md 3.1).
- Every commit ends with `Co-authored-by: Claude (<your own session's model id>) <noreply@anthropic.com>` (AGENTS.md 3.3). Use the id of the model actually writing the commit, never a literal copied from this plan: the rule exists so per-model contribution stays distinguishable. The commit blocks below show the trailer with a placeholder for that reason.
- Do not commit HTML, images, SVGs or other web artifacts (AGENTS.md 7). `docs-site/site/` must be gitignored before anyone runs a local build.
- Python dependencies go through `uv` only. Never edit `pyproject.toml` dependency tables or `uv.lock` by hand (AGENTS.md 4).
- Tests live at `tests/test_*.py` and run via `uv run --frozen --all-extras pytest`, never bare `pytest` (AGENTS.md 5).
- Do not commit or push unless the user explicitly asks (AGENTS.md 3.4, 3.6). The commit steps below are written out, but each still needs the user's word.
- `mkdocs-static-i18n` must be >= 1.0: the 1.0 release replaced the old dict-style `languages:` mapping, and a pre-1.0 config does not validate on current releases.
- Site URL is `https://evermind-ai.github.io/Raven/` and must appear verbatim as `site_url` in `mkdocs.yml` and in both READMEs' pointers.

### Task 2: Guard the site's page shape

Written before the pages exist, so the guards are what the content has to satisfy.

**Files:**
- Create: `tests/test_docs_site.py`

**Interfaces:**

- [ ] **Step 1: Write the failing tests**

Create `tests/test_docs_site.py`:

```python
"""The documentation site's pages keep the two properties a broken move costs.

A repository-relative link in a .md page is already caught by mkdocs build
--strict; this guard catches non-.md targets (e.g., docker/.env) that --strict
misses, and runs in the ordinary test suite without needing the docs uv group.
A page added in one language only leaves the other language's reader on a
fallback they cannot tell from a translation.
"""

from __future__ import annotations

import re
from pathlib import Path

REPO = Path(__file__).resolve().parent.parent
SITE = REPO / "docs-site" / "docs"

LINK = re.compile(r"\[[^\]]*\]\(([^)]+)\)")


def _pages() -> list[Path]:
    return sorted(SITE.glob("*.md"))


def test_every_page_has_both_languages() -> None:
    english = {path.stem for path in _pages() if not path.name.endswith(".zh.md")}
    chinese = {path.name[: -len(".zh.md")] for path in _pages() if path.name.endswith(".zh.md")}

    assert english == chinese, (
        f"English page without a Chinese twin: {sorted(english - chinese)}; "
        f"Chinese page without an English twin: {sorted(chinese - english)}"
    )
    assert english, "no pages found -- did SITE move?"


def test_no_page_links_into_the_repository_by_a_relative_path() -> None:
    pages = _pages()
    assert pages, "no pages found -- did SITE move?"
    offenders: list[str] = []
    for page in pages:
        for target in LINK.findall(page.read_text(encoding="utf-8")):
            link = target.split("#", 1)[0].split(" ", 1)[0]
            if not link or link.startswith(("http://", "https://", "mailto:")):
                continue
            if "/" not in link and link.endswith(".md"):
                continue
            offenders.append(f"{page.name} -> {target}")

    assert not offenders, (
        "repository-relative links in non-.md targets are not caught by mkdocs "
        "build --strict; make them absolute github.com URLs: "
        f"{offenders}"
    )
```

A bare `*.md` with no slash is an intra-site page link and is skipped here on
purpose: whether the target exists is `mkdocs build --strict`'s job, and it
reports a dangling one by name. Checking existence here as well would make this
test fail on a page that is merely written before its neighbour, which is the
order Task 3 uses.

**Files:**

- [ ] **Step 1: Write the workflow**

Create `.github/workflows/docs.yml`:

```yaml
name: Docs

on:
  push:
    branches: [main]
  pull_request:

concurrency:
  group: docs-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  build:
    name: docs build
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v7
      - name: Install uv
        uses: astral-sh/setup-uv@v8.2.0
        with:
          enable-cache: true
          cache-dependency-glob: uv.lock
      - name: Set up Python
        run: uv python install 3.12
      - run: uv run --frozen --group docs mkdocs build -f docs-site/mkdocs.yml --strict
      - uses: actions/upload-pages-artifact@v5.0.0
        with:
          path: docs-site/site

  deploy:
    name: docs deploy
    needs: build
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    runs-on: ubuntu-latest
    timeout-minutes: 10
    permissions:
      pages: write
      id-token: write
    concurrency:
      group: docs-pages-deploy
      cancel-in-progress: false
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v5.0.1
```

The two Pages actions are pinned at the v5 line on purpose. The v3/v4 pair
declares the `node20` runtime, which GitHub removes from its runners on
2026-09-23; `upload-pages-artifact` sits in the build job, so past that date
every pull request's docs build fails, not only the deploy. The deploy job takes
its own non-cancelling concurrency group because `deploy-pages` calls the Pages
API to start a deployment and cancelling that mid-flight can wedge the
deployment record; a build is cheap and idempotent and still prefers the newest
commit.

```python
"""The repo-layout table stays equal to the tree it declares canonical.

The table is the canonical set of commit scopes (AGENTS.md section 3.1), and
commitlint.config.cjs computes its scope enum from the same tree -- so a
package added or removed without its table row would silently split the two.

Both language copies are checked. The rows are backticked identifiers and are
identical across languages; only the description column differs. Guarding one
copy would let the other drift, which is the state this file inherited when
the table lived in README.md alone.
"""

from __future__ import annotations

import re
from pathlib import Path

REPO = Path(__file__).resolve().parent.parent
PAGES = (
    REPO / "docs-site" / "docs" / "repo-layout.md",
    REPO / "docs-site" / "docs" / "repo-layout.zh.md",
)

TABLE_ROW = re.compile(r"^\| `([a-z0-9_]+)` \|", re.MULTILINE)


def _packages_on_disk() -> set[str]:
    packages = {
        entry.name for entry in (REPO / "raven").iterdir() if entry.is_dir() and (entry / "__init__.py").exists()
    }
    modules = {
        entry.stem for entry in (REPO / "raven").glob("*.py") if entry.name not in {"__init__.py", "__main__.py"}
    }
    return packages | modules


def test_repo_layout_table_equals_the_packages_on_disk() -> None:
    expected = _packages_on_disk()

    for page in PAGES:
        assert page.exists(), f"{page.name} is gone; the canon has no home"
        rows = set(TABLE_ROW.findall(page.read_text(encoding="utf-8")))
        assert rows == expected, (
            f"{page.name}: table without a package on disk: {sorted(rows - expected)}; "
            f"package on disk without a table row: {sorted(expected - rows)}"
        )


def test_key_directories_block_names_the_product_and_plugin_trees() -> None:
    for page in PAGES:
        text = page.read_text(encoding="utf-8")
        assert re.search(r"^agents/\s", text, re.MULTILINE), f"{page.name} lost its agents/ line"
        assert re.search(r"^plugins-dist/\s", text, re.MULTILINE), f"{page.name} lost its plugins-dist/ line"
```
